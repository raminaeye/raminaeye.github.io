Score every channel from its own average, then turn the useful ones up and the rest down.

Squeeze-and-excitation is a small add-on to any CNN block, not a network on its own. It runs on every forward pass, in training and at test time, and carries only the learned gate weights between steps, no running state. Related, not prerequisite: the MobileNetV2 block (MobileNet and MobileNetV2) and compound scaling (EfficientNet Compound Scaling), where SE reappears inside every EfficientNet B0 block.

1 Some channels matter more than others

A convolution treats every channel equally, but channels carry different features and some matter more than others for a given image. Squeeze-and-excitation (Hu et al. 2018) scores each channel from the image itself and rescales it, so useful channels get louder and the rest quieter.

ImageNet is a labeled photo set with 1,000 classes; top-1 error is the share of test photos whose highest-scoring class is wrong, and top-5 error the share whose right class is outside the top five guesses. Trained on ImageNet, adding SE to ResNet-50 lowers its error at almost no extra cost, and the deepest SENet won the ILSVRC 2017 classification.

2 Squeeze: one number per channel

Global average pooling squeezes each channel map to one number. The channel map is bold \(\mathbf{u}\), \(H\) and \(W\) its height and width, and \(z\) the average. The squeeze line of the card in section 4 reads: each channel map collapses to its average, one number per channel. The average throws away where a feature fired and keeps how much of it there is.

3 Excite: two small layers score the channels

The bottleneck runs \(C\) to \(C/r\) to \(C\), where \(r\) is the reduction ratio: ReLU, which keeps positive values and sets negative ones to zero, then sigmoid, one score per channel between 0 and 1. The excitation line of the card in section 4 reads: the averages go through two small linear layers, down to \(C/r\) channels and back to \(C\), and the sigmoid squeezes every score into 0 to 1.

The reduction ratio \(r\) sets the gate's hidden width \(C/r\): raising it shrinks the gate and its cost, lowering it gives the gate more capacity, and \(r\) = 1 keeps the full width; the paper uses 16 by default (SENet paper section V-A). The gate weights are two small layers, \(C\) by \(C/r\) and \(C/r\) by \(C\), so one gate holds two times \(C\) squared over \(r\) weights (paper eq 5, per-block form); the total across SE-ResNet-50 is about 2.5 million added weights, about 10% more (paper section IV).

4 Scale: multiply each channel by its score

The scale line of the card below reads: each channel map is multiplied by its own score, so a useful channel stays loud and a useless one fades. The walkthrough steps through all three lines in turn.

Squeeze: each channel map collapses to its average.

Squeeze, excite, scale: three lines, one per step.
\(\displaystyle z_c = \frac{1}{H W} \sum_{i=1}^{H} \sum_{j=1}^{W} \mathbf{u}_c(i, j)\)
The squeeze. Each channel map \(\mathbf{u}_c\) collapses to its average \(z_c\), one number per channel. \(H\) and \(W\) are the map height and width, \(i\) and \(j\) the positions summed over. The average throws away where a feature fired and keeps how much of it there is.
\(\displaystyle \mathbf{s} = \sigma(\mathbf{W}_2 \delta(\mathbf{W}_1 \mathbf{z}))\)
The excitation. The vector of channel averages \(\mathbf{z}\) goes through two small linear layers: \(\mathbf{W}_1\) squeezes it down to \(C/r\) channels, \(\delta\) (ReLU) bends it, \(\mathbf{W}_2\) lifts it back to \(C\) channels, and \(\sigma\) (sigmoid) squeezes every score into 0 to 1. \(\mathbf{s}\) is the score per channel, and the gate weights \(\mathbf{W}_1\) and \(\mathbf{W}_2\) are learned.
\(\displaystyle \tilde{\mathbf{x}}_c = s_c \mathbf{u}_c\)
The scale. Each channel map \(\mathbf{u}_c\) is multiplied by its own score \(s_c\), so a useful channel stays loud and a useless one fades. It builds on the excitation line: it uses the score \(\mathbf{s}\) that line produced.

5 The gate at work

Added to every ResNet-50 block with \(r\) = 16, SE adds almost no compute but about a tenth more weights, most of them in the last, widest stage. Compute rises 0.26%, from 3.86 to 3.87 GFLOPs (billions of multiply-add operations per image), and weights rise about 10%, from about 25M to 28.1M (paper section IV and Table II). The authors' code is at github.com/hujie-frank/SENet.

SE plugs into SE-ResNet, SE-ResNeXt, SE-Inception-ResNet and SE-MobileNet. The ResNet family architectures are in SENet paper Table I; results are in Table II for ResNet, ResNeXt and Inception-ResNet, and in Table III for MobileNet. SE-MobileNet adds almost no compute or weights, at 572 against 569 MFLOPs, millions of multiply-add operations, and 4.7M against 4.2M weights (paper Table III). Every EfficientNet B0 block carries the same step (EfficientNet Compound Scaling).

In the block below, for maps \(x\) of shape [\(B\), \(C\), \(H\), \(W\)] (batch, channels, height, width), the mean squeezes each map to one number \(z\), two small linear layers turn those into a 0 to 1 score \(s\) per channel, and the last line rescales the maps. 

import torch
import torch.nn as nn

class SEBlock(nn.Module):
    def __init__(self, C, r=16):
        super().__init__()
        self.gate = nn.Sequential(
            nn.Linear(C, C // r),
            nn.ReLU(),
            nn.Linear(C // r, C),
            nn.Sigmoid())

    def forward(self, x):
        z = x.mean((2, 3))
        # z: [B, C]
        s = self.gate(z)  # 0 to 1
        s = s[:, :, None, None]
        return x * s

x = torch.randn(2, 64, 28, 28)
print(SEBlock(64)(x).shape)
# [2, 64, 28, 28]
  1. 1The gate: \(C\) to \(C/r\) to \(C\), then a sigmoid to 0 to 1.
  2. 2Squeezes each map to its mean \(z\).
  3. 3Turns \(z\) into one score \(s\) per channel.
  4. 4Rescales every map by its score \(s\).

6 Failure modes and tips

Each failure here comes from a gate choice the paper measured, so each fix names its table.

A gate narrowed too far. Symptom: accuracy slips as the gate thins. Cause: a reduction ratio too large narrows the gate too far and accuracy slips; keep \(r\) = 16 unless the ablation says otherwise for the network at hand.

Squeezing by max pooling. Symptom: the gate scores slightly worse. Cause: max pooling keeps only the strongest response, where average pooling keeps how much of the feature there is; max pooling scores slightly worse (paper Table XI). Fix: use global average pooling.

A gate that is not a sigmoid. Symptom: accuracy falls below the network without SE. Cause: replacing the sigmoid gate with ReLU scores below the network without SE, and tanh scores below the sigmoid (paper Table XII). Fix: keep the sigmoid gate.

Gate cost checked only as a total. Symptom: the gate looks cheap until the last stage. Cause: the weight cost concentrates in the late, widest stages. Adding SE to one stage at a time helps, and the late stages help most: stage 4 alone at 26.4M weights, stages 2 and 3 at 25.6M and 25.7M, all stages at 28.1M (paper Table XIII). Each stage helps, late stages help most and cost most: stage 4 alone adds about 0.8M weights while stages 2 and 3 add about 0.1M each or less. Fix: check the gate cost per stage, not just the total.

Tips: keep \(r\) = 16; check the gate cost per stage; removing the costly last stage costs little accuracy (paper section IV). The blocks are cheap and well weighted, but how do you grow the whole network? EfficientNet Compound Scaling answers that.
