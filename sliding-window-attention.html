Full attention scores every pair of tokens (its cost grows with the square of the length), and its KV cache grows with every token. In online speech recognition or live translation, the future has not even been spoken yet.

1 Each token looks back a fixed window

In a long chat, or in online speech recognition (often trained with CTC loss), each query can look back only a fixed number of tokens or frames (time slices of the input, such as 10 ms of audio), and everything older is masked out.

The window mask. This page's convention: the window holds \(w\) tokens including the token itself.
\({\displaystyle M_{ij}=0\text{ if }i-\htmlClass{eqt sym-w}{\htmlStyle{color:#117a7a}{w}}<j\le i}\)
Think of a long chat, or speech being recognized as it is spoken. Query \(i\) may read itself and the tokens just before it inside the window, so those keys keep their scores.
\({\displaystyle M_{ij}=-\infty\text{ otherwise}}\)
Every other key gets negative infinity. Mistral writes its window as the positions from \(i\) back to \(i - W\), a count one larger than this page's; with \(w\) as long as the whole text, this is the plain causal mask again.
\({\displaystyle \htmlClass{eqt sym-s}{\htmlStyle{color:#9a6400}{S}}=\frac{\htmlClass{eqt sym-q}{\htmlStyle{color:#7d3c98}{Q}}\htmlClass{eqt sym-k}{\htmlStyle{color:#a04000}{K}}^{\top}}{\sqrt{d_k}}+M}\)
Adding \(M\) to the scores \(S\) gives every key outside the window a score of negative infinity. \(d_k\) is the number of entries in each key; dividing by its square root keeps the scores from growing with the head size.
\({\displaystyle O=\mathrm{softmax}(\htmlClass{eqt sym-s}{\htmlStyle{color:#9a6400}{S}})\,\htmlClass{eqt sym-k}{\htmlStyle{color:#a04000}{V}}}\)
Softmax turns those scores into zero weight, so each row of the output \(O\) averages only the values inside its window. This is attention with a band-shaped mask.
windowquerieskeys and valuesscores
import torch

n, w = 10, 3  # frames, window
NEG_INF = float("-inf")
mask = torch.full((n, n), NEG_INF)  # added to the scores
for i in range(n):
    start = max(0, i - w + 1)  # oldest frame query i reads
    mask[i, start:i + 1] = 0
  1. 1Starts with every score blocked at negative infinity, the second case of the mask line.
  2. 2Opens the window: the last \(w\) frames up to and including each query, the first case of the mask line.
Scores computed per layer: full attention on the first line, the window on the second.
\({\displaystyle \text{scores}_{\text{full}}=\htmlClass{eqt sym-n}{\htmlStyle{color:#9a6400}{n}}^{2}}\)
Full causal attention scores every query against every earlier key, so the count grows with the square of the length \(n\).
\({\displaystyle \text{scores}_{\text{window}}=\htmlClass{eqt sym-n}{\htmlStyle{color:#9a6400}{n}}\,\htmlClass{eqt sym-w}{\htmlStyle{color:#117a7a}{w}}}\)
Each query scores \(w\) keys instead of \(n\), so for a fixed window the cost grows in a straight line with the length \(n\), not with its square as in the attention cost card.

2 Stacked layers reach further back

A token outside the window is not lost. Each layer's outputs already carry their own window's context, so after several layers information has moved forward several windows, like a receptive field; the Mistral paper notes that tokens outside the window still influence the prediction.

How far back the top layer can see.
\({\displaystyle \text{reach}_{\htmlClass{eqt sym-kl}{\htmlStyle{color:#1f618d}{k}}}\approx \htmlClass{eqt sym-kl}{\htmlStyle{color:#1f618d}{k}}\,\htmlClass{eqt sym-w}{\htmlStyle{color:#117a7a}{w}}}\)
Each layer moves information forward by up to one window, so after \(k\) layers the top token can depend on tokens about \(k\) windows back; \(\text{reach}_k\) is that reach. Mistral writes this as \(k\) times its window; Longformer gets the same reach for its two-sided window.

Figure 2. Window, depth and reach: chat tokens in a Mistral-style decoder.

Size the window from the smallest unit the task must capture (a phoneme, one distinct sound of a language; a gesture; a word), converted to tokens or frames, and let depth carry the rest.

3 A rolling buffer caps the cache

A model trained with a window, such as Mistral 7B, never reads a key older than the window, so its cache needs only \(w\) slots. Each new token overwrites the slot of the token one window older, and the cache stops growing. Mistral reports that this cuts cache memory 8 times on 32k-token sequences without hurting quality. Long prompts are prefilled in window-sized chunks.

Where token \(i\) goes in a rolling buffer.
\({\displaystyle \mathrm{slot}(i)=i\bmod \htmlClass{eqt sym-w}{\htmlStyle{color:#117a7a}{w}}}\)
\(i \bmod w\), read “\(i\) mod \(w\)”, is the remainder after dividing \(i\) by \(w\), so the slot numbers climb to the end and start again at the first, reused in a circle. The cache has \(w\) slots, one per window position. Token \(i\) writes slot \(i \bmod w\), overwriting the token \(w\) steps older, which is already outside every later query's window under the mask line.
window

This works because the model was trained with the window. A model pretrained with full attention breaks when its cache is cut this way, and needs a few first tokens kept as well: Attention Sinks and Streaming Generation.

5 Windows plus a few global tokens

Longformer (Beltagy et al. 2020) uses the window in an encoder, so it is centred: each token attends \(w/2\) tokens on each side, not only the past. A few task-chosen global tokens attend to everything and are attended by everything: for classification, the [CLS] token, a special token placed at the start whose output stands for the whole text; for question answering, the question. They add full rows and columns to the window mask. Some heads use dilation, leaving gaps between the keys they read so one window spans further at the same cost, and the cost still grows in a straight line with length. After \(k\) layers its reach is \(k\) times the window, the same as the reach card.

6 Choosing the window

WhenThe mask runs in every attention layer, in training and inference; the cache holds at most \(w\) entries per layer.
Window \(w\)Wider sees more per layer at more scores per query; narrower is cheaper and needs more layers to reach far. At one a token sees only itself; at the full length it is plain causal attention. Mistral 7B sets its window, which Mistral calls W, to 4096 tokens with an 8192-token context.

For long encoder documents with a task token, use Longformer's global attention; for decoders trained with a window, the rolling buffer; for full-attention decoders streamed past their cache, a window plus attention sinks.
