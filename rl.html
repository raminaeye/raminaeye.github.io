1 Learning from rewards

Many tasks give no labelled answers, only a reward after each try. How can a learner get better from those rewards alone?

The running example is my banana collector, built in the Unity game engine, a learner in a square arena that should gather yellow bananas and avoid blue ones.

Reinforcement learning

What. Picture a learner with no right answers, only a number after each try. Learning from rewards like this is called reinforcement learning, or RL for short.

How. The learner tries a move, hears how good the result was, and tries again, and each try teaches it a little.

Why. When it works, the learner finds good moves without ever being shown one.

Figure 1 shows the arena the whole page keeps coming back to. The yellows are the bananas to gather, the blues are the ones to avoid, and their pay is all the agent ever hears.

Once trained, the collector gathers yellows quickly and steps around blues.

2 The reinforcement learning loop

Here the agent is the banana collector, the learner that picks the moves. It is paid for each yellow banana it eats and charged for each blue one, but it is not told in advance which steps pay; it finds out only by stepping. A state is the agent’s situation right now. A move, or action, is one choice the agent can make in a state, and a reward is the number the world hands back after each move, good or bad.

In the arena most steps meet no banana, so most steps bring no reward at all. The collector may always pick the same move or pick by chance. The collector sees the bananas around it and must decide which way to step from each spot.

The world can be random too, so the same move in the same state does not always lead to the same next state or reward. New bananas drop in new places, so the collector’s path changes from one run to the next.

Moves go down, rewards come back

What. Picture the collector on one spot, choosing a step, and the world answering. The environment is everything outside the agent that responds and hands back a reward.

How. The policy, the agent’s rule for choosing a move in each state, picks a move. The world applies it and hands back a reward and the next state, and the agent learns from each reward.

Why. When it works, each step leaves the agent a little surer of which way to step from each spot.

Figure 2 shows the loop the agent repeats for its whole training, one move answered by a reward and a next state. The move goes down to the world, and the reward and the next state come back up, so the two arrows matter more than the two boxes.

3 The banana collector environment

The collector sees only its sensors

What. Picture a small square room the collector sees only through its sensors. An episode is one run from the start until it ends, and a discrete action is one move from a fixed short list.

How. The collector reads the arena through a list of sensor readings, one list per step, and chooses from only four moves.

Why. When it works, that tiny pay, a gain for a yellow banana and a loss for a blue one, is enough to turn guessing into good play.

The arena's clock ends the run.

The collector sees the arena only through 37 sensor readings and chooses from only four moves, so every score on this page is about those readings and those moves.

The loop in code starts with a policy that picks every move by chance.

from unityagents import UnityEnvironment

env = UnityEnvironment(file_name="Banana.app")
brain_name = env.brain_names[0]
env_info = env.reset(train_mode=True)[brain_name]
  1. 1Bring in the Unity wrapper and make the world.
  2. 2Take the first state of an episode; a brain is Unity’s name for the part that decides the moves.
import numpy as np

action = np.random.randint(4)  # a move drawn by chance
  1. 1Draw a move by chance.
env_info = env.step(action)[brain_name]
next_state = env_info.vector_observations[0]
reward = env_info.rewards[0]
done = env_info.local_done[0]
  1. 1Send the move and read back the next state, the reward and whether the run ended.

The snippet follows the Value-based-methods repo’s pinned versions, the unityagents package with Python 3.6; the ML-Agents Toolkit, the Unity toolkit the snippet is written against, has since changed its API.

4 Why copying an expert is not enough

Behaviour cloning

What. Picture an expert’s recorded routes through the arena, and a learner copying them. Behaviour cloning is copying an expert’s recorded moves as labels and training on them.

How. The expert’s recordings show only a few routes through the arena, and the rest of it stays unseen, so the collector has only its rewards to learn from.

Why. When copying works, it needs a recorded right answer for every step, and this arena has none.

Language models are first trained this way, by copying example replies, before reinforcement learning from human feedback (RLHF) improves them, as Aligning Language Models with RL shows. In the arena the collector learns from its rewards alone.

Figure 3 shows the two ways to learn side by side. The top half needs labels the arena never had; the bottom half is all the collector gets, a reward after each try.

5 Why RL is hard

A yellow banana sits in the open while another hides behind a blue one, so the collector must choose which to head for first.

Later bananas count for less

What. Picture the collector choosing between a yellow banana one step away and a better route three steps on. The return is all the reward still to come, with later rewards counted a little less.

How. Each later reward is shrunk by the discount, the share of a reward’s worth kept for each step of delay, so nearer bananas count more.

Why. When it works, the collector heads for the route that pays most over the whole run, not just the next banana.

Figure 4 shows why a reward that arrives later is worth less than one that arrives now. The bars under the steps fade the further ahead they are.

Equation 1. The collector has to choose between a banana now and a better route later. A delivery robot choosing between a quick drop-off now and a fuller route later faces the same choice.

The plus sign adds on \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+2}}}\), the reward one step further on, shrunk once by the discount. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\) equals \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) plus \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) times \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+2}}}\).

Intuition. The sum does not stop at two rewards: it runs on, each reward shrunk once more per step.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma^{2}}}\) is the discount applied twice, once per step of delay. \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+3}}}\) is the reward three steps after the move, shrunk twice. The plus sign adds it on, and the dots mean more terms follow, each shrunk once more per step, to the end of the episode. This line adds \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma^{2}}}\) times \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+3}}}\) to the sum.
Example. Take a run that earns bananas at the first, third, and last steps: each later banana joins the sum shrunk once more per step of delay.
3\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}} = \sum_{\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{k}}} \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma^{k}}}\, \htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+k+1}}}\)
Intuition. The whole sum fits in one line: every future reward, each shrunk by the discount once per step of delay. It is the sum built up reward by reward: the first at full worth, the next shrunk once, the next shrunk twice, and so on to the end of the episode.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\) is the return from step t. The big sum sign means add up, over every k. k counts steps of delay, so k equals zero is the next reward at full worth, and k equals one is the reward one step further on, shrunk once. \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma^{k}}}\) is the discount applied k times, and \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+k+1}}}\) is the reward k-plus-1 steps after the move. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\) equals the sum over k of \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma^{k}}}\) times \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+k+1}}}\).
Example. Take a run that earns a banana at every step: the sum adds them all, each shrunk once more than the one before, and k counts how many steps of delay each one carries.
4\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}} = \htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}} + \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\, \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_{t+1}}}\)
Intuition. The return can be written in one step: the next reward, plus the same return counted from the step after, the same sum built up reward by reward from the start.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\) is the return from step t. \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) is the reward right after the move at step t. \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) is the discount, the share of a reward's worth kept for each step of delay. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_{t+1}}}\) is the return from the next step, the same later rewards, each with one fewer discount applied. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\) equals \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) plus \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) times \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_{t+1}}}\). This line is that whole sum written in one step: the next reward plus the discounted return from the step after.
Example. Take a run with no banana for three steps, then a yellow one: the return from the first spot is just that later banana, shrunk once per step.
Take the collector standing one step from a yellow banana, with a blue banana just past it. The return from that spot counts the yellow banana it is about to eat at full worth, then the blue banana after it shrunk once by the discount, then every banana after that shrunk once more per step, until the clock ends the episode.

Figure 5 shows the discount from Equation 1 at work, how a reward loses worth with every step of delay. The three buttons set the discount to small, middle, or large, and the bars redraw, shrinking from left to right as the delay grows. The tool opens on the middle setting, a discount of 0.8. 6 Scoring states and moves with values

6.1 What a spot and a move are worth

Spots and moves have scores

What. Picture the arena floor shaded by how good each spot is. A spot is worth the return to expect from standing on it, and a move is worth the return to expect after making it.

How. An expected value is the average over everything that can happen by chance, weighted by how likely each outcome is, so the score already allows for luck.

Why. When it works, the collector can compare spots and moves before it moves, and head for the spots worth most.

Figure 6 shows what a state's value looks like on the floor: darker spots are worth more. The dark corner sits beside the yellows and the pale corner beside the blues, so the shading is the collector's whole knowledge about where to stand.

Equation 2. Once the return scores a whole run, the agent needs to compare spots and moves before it moves. A warehouse robot that must pick which aisle to enter next needs the same scores.

1\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}) = \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\big[\, \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}} \mid \htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}} = \htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}} \,\big]\)
Intuition. A spot is worth what the runs from it earn on average, so spots can be compared before moving. The move value scores a single move first, while this line averages over the moves the policy plays first.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\) is the state value under the policy, the score for a spot. \(\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}\) on top marks the policy, the rule for choosing moves. s names the spot scored. \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\), with \(\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}\) below, is the average over runs: take each run from this spot, multiply its return by its chance, and add them up. Inside the brackets sits \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\), the return from Equation 1. The bar reads given \(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}\) is s. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}})\) equals \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\) of \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\), given \(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}\) is s.
Example. Take a spot one step from a yellow banana and two steps from a blue one: most runs from there earn the yellow first.
2\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}}) = \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\big[\, \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}} \mid \htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}} \,\big]\)
Intuition. A move is worth what the runs after it earn on average, so moves from one spot can be compared.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\) is the move value under the policy, the score for a move. \(\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}\) on top marks the policy. s names the spot and a names the move scored, one of the collector's four moves. \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\) is the same average over runs as the spot value's. Inside it sits \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\), the return from the move on. The bar reads given the step's spot is s and the move is a. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}})\) equals \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\) of \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\), given the step's spot is s and the move is a. Q connects to V, the spot's value: Q is the spot's value once the first move is fixed.
Example. Take a spot where two moves both reach a yellow banana, but one passes a blue one first: the safer move scores higher, while the spot's value averages both moves.
Take the collector on the spot one step from a yellow banana. Stepping toward it eats the banana on the next move, and the runs after that step branch from the spot past the banana, while stepping away leaves the banana for later runs, so the two moves carry different values even though they start from the same spot.

Before training, the agent has no idea which spots lie near yellows.

Best play is the goal of the whole page: the policy that earns the most return. \(Q^{*}\) is each move’s value under that best policy, the score the learning is aiming at, not the score the agent already has. It is not \(Q^{\pi}\), which scores moves under the policy the agent is following now, and nobody hands the collector that policy; it has to find it by stepping.

6.2 Improving a guess after one step

The collector does not know \(V\) for any spot, so it keeps a guess for each spot and improves it.

A guess needs something to aim at: a target, the value a guess is pulled toward. Monte Carlo, or MC for short, builds its target from the whole return. TD stands for temporal difference, the difference between two guesses a step apart, and one-step TD builds its target from one step's reward plus the guess for the next spot.

Targets and the one-step update

What. Picture the collector guessing how good each spot is, with nothing to aim at.

How. Each step brings a small surprise, the gap between the target and the guess, and each surprise moves a guess a little.

Why. When it works, the guesses for spots near yellows end up higher than those near blues, and the surprise averages out to zero.

Figure 7 shows the two timelines side by side. The timelines differ in only one thing, when the update happens, and that difference is what lets one-step TD learn from every step instead of waiting for a run to end.

Equation 3. The agent's guesses need something to aim at. A self-driving car that must judge whether a turn was good needs the same choice.

1\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\text{MC}}_t = \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\)
Intuition. A target is the value a guess is pulled toward. The Monte Carlo target is the return the run really earned, exact for that run.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\text{MC}}_t\) is the Monte Carlo target at step t, the value the guess is pulled toward. MC on top stands for Monte Carlo, and t below is the step the target belongs to. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\) is the return from Equation 1, the score for the run starting at that step: the banana rewards still to come, added up with the discount. \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\text{MC}}_t\) equals \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{G_t}}\).
Example. Take a run where the collector eats two yellow bananas before the clock ends the episode: the Monte Carlo target is the full discounted score of that run.
2\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\text{TD}}_t = \htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}} + \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\, \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}})\)
Intuition. One step's reward plus a guess for the next spot: a target leaning on a guess.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\text{TD}}_t\) is the TD target at step t, the value the guess is pulled toward. TD on top stands for temporal difference, the difference between two guesses a step apart, and t below is the step the target belongs to. \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) is the reward just seen. \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) is the discount, and \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}})\) is the guess for the next spot, with no policy mark. The plus sign adds on \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) times \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}})\). \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\text{TD}}_t\) equals \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) plus \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) times \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}})\).
Example. Take a step where the collector eats nothing: the TD target is the discounted guess for the spot it lands on.
Take a step where the collector eats a yellow banana and lands one step from another. The TD target adds the yellow banana just eaten to the discounted guess for the spot it landed on. The two targets agree only when the guess for the new spot already matches what the runs from there really earn.

Equation 4. The agent now has targets to aim at and values to move. A chess program that updates its judgment of a position after each move follows the same rule.

1\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}_t = \htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}} + \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\, \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}})\)
Intuition. The true target under the policy is one step's reward plus the true value of the next spot. It is the TD target with true values in place of the agent's guesses.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}_t\) is the target at step t, the step the target belongs to, under the policy, the value the guess is pulled toward. \(\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}\) on top marks the policy. \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) is the reward just seen, and \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) is the discount. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}})\) is the true value of the next spot, the state value under the policy, the return to expect from there. The plus sign adds on \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) times \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}})\), the discounted true value of the next spot. \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}_t\) equals \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) plus \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}}\) times \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}})\). It is the same shape as the TD target, one reward plus the discounted guess for the next spot, but with the true values \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\) in place of the agent's guesses.
Example. Take the collector stepping toward a yellow banana not yet reached: the target is the step's reward plus the true value of the spot it lands on.
2\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}) = \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\big[\, \htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}_t \mid \htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}} \,\big]\)
Intuition. The true value of a spot is the average of the true targets over everything that can happen next. It averages the true target, one step's reward plus the true value of the next spot, the way the spot value averaged the return.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}})\) is the true value of the spot the agent stands on. \(\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}\) on top marks the policy. \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\), with \(\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}\) below, is the average over what can happen next, built the same way as the spot and move values: each possible next move and next spot, its target times its chance, added up. Inside the brackets sits \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}_t\), the true target, one step's reward plus the true value of the next spot. The bar reads given \(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}\). \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}})\) equals \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\mathbb{E}}}_{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}\) of \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi}}}_t\), given \(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}\). The true value is the average of the true target over everything that can happen next.
Example. Take a spot with two moves, one toward a yellow banana and one away: the true value averages both moves' targets by their chances.
3\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#b03a2e}{\delta_t}} = \htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\text{TD}}_t - \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}})\)
Intuition. The surprise is the gap between target and guess: positive when the step went better than guessed.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#b03a2e}{\delta_t}}\) is the TD error at step t, the step the error belongs to, the target minus the current guess. \(\htmlClass{eqt}{\htmlStyle{color:#196f3d}{y}}^{\text{TD}}_t\) is the TD target, one reward plus the discounted guess for the next spot, and \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{V}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}})\) is the agent's current guess for the spot it stands on, with no policy mark. Intuition. Each step moves the guess part of the way toward the target.
The mathematics. Together the four lines say one thing: aim at the true target, measure the surprise, and move the guess.
Example. Take a step where the collector eats a blue banana, with the guess for the spot rated highly: the guess falls part of the way.
Take the collector standing one step from a yellow banana with a low guess for that spot. It steps toward the banana and eats it, so the target comes out above the old guess, the surprise is positive, and the guess for the spot it stood on moves part of the way toward the target. Step after step, the guesses for the spots near the banana rise.

Each guess moves with a learning rate of 0.1 in this example, so each guess moves a tenth of its surprise per step. Raising the learning rate moves guesses further each step, faster but jumpier; lowering it moves them less, slower but steadier.

7 Explore early, exploit late

If the agent keeps a score for every move, it faces a choice at every step: play the best-scored move or try one it knows less about. Equation 5 writes the rule that balances the two.

Explore and exploit

What. Picture the collector at a crossing, one move scored above the rest and the rest untried. Exploration means trying moves to learn what they do; exploitation means playing the best-scored move.

How. The balance is set by the explore share, called epsilon, the chance of a random move. The greedy move is the best-scored move, and it can hide a better route the agent never tried.

Why. When it works, the collector tries enough new routes to find the yellows its best-scored move never turns toward, then settles on the best route it knows.

Equation 5. Values tell the agent which move scores best, but the best-scored move is only as good as the scores behind it, and untried moves have no scores at all. A streaming service choosing which film to recommend faces the same balance.

1\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}} = \arg\max_{\htmlClass{eqt}{\htmlStyle{color:#a04000}{a}}}\, \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}})\)
Intuition. The greedy move is the best-scored move. The agent plays it whenever it is not trying a random move, which is why it needs a random move alongside it, tried with chance epsilon, to find better routes.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}}\) is the move at step t, one of the collector's four moves. argmax over a picks the move whose score is largest, scanning every move the agent can make. \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}})\), with no policy mark, is the agent's current move score for move a in the spot \(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}\), the move value as the agent currently estimates it. \(\htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}}\) equals the move with the largest score over a of \(\htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}})\): the move played has the largest score. A random move, tried with chance \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\epsilon}}\), is any of the four moves, picked with no regard to its score.
Example. Take the collector at a crossing with one move scored above the rest: the greedy line plays that move.
2\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}} = \text{random move} \ \text{with chance } \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\epsilon}}\)
Intuition. Sometimes the collector ignores the scores and tries a random move.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}}\) is the move at step t. \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\epsilon}}\) is the explore share, the chance of a random move: any move, picked with no regard to its score. Raising it tries more and uses what is known more slowly; lowering it may never find a better route. \(\htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}}\) equals a random move, with chance \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\epsilon}}\). The random draw picks from all four moves, so the best-scored move can come up there too: the greedy move is played for most of the time: start with all of the time, take away the explore share, then add back a quarter of that share. With \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\epsilon}}\) at 0.1, that is 0.9 plus 0.025, which is 0.925. This rule is called \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\epsilon}}\)-greedy.
Example. Take the collector on a spot where every move scores low: a random step can stumble on a yellow banana no move had scored.
Take the collector at a crossing where one move leads toward a yellow banana and the others lead away. It plays the best-scored move toward the banana, and once in a while it tries a move at random instead. That random step is how it can stumble on a banana it had never scored, and the scores it learns from the stumble are what the greedy move uses next time.

An agent can also shrink \(\epsilon\) a little after every episode, so early on it mostly explores and late in training it mostly plays its best-scored move; Q-Learning, which learns a score for every move from one step at a time, shows the rule.

def epsilon_greedy(q_values, eps):
    if np.random.rand() < eps:
        return np.random.randint(len(q_values))
    return np.argmax(q_values)

Exploring is easiest to watch on a small floor where every step can be seen. A warehouse robot looks for its charging dock; the ledge is the strip of floor between the start and the dock. It starts in one bottom corner and the dock sits in the other. Each move’s reward is minus the battery it uses, so the best total is the one closest to zero. Stepping onto the ledge costs a lot and puts the robot back at the start; only reaching the dock ends the episode. The cheapest way to the dock is the shortest path that never steps onto the ledge, and it runs right beside the ledge, so one random step there is a fall.

9 The trained banana agent

Figure 10 shows the trained agent at work: its path bends around the blue bananas on its way to the yellows, showing the scores it learned, and at one bend it turns away from a blue banana right in its path and reaches the yellow behind it instead.

My trained agent learns a score for each move with a neural network, as in Deep Q-Networks (DQN). Over training the agent’s total reward per episode climbs as it learns to head for yellows.

The agent trains only every fourth move, on a small batch drawn from a large memory of past steps, so most moves are just play and only some are study. The memory matters because each step can be learned from more than once, and a batch drawn from many past runs is steadier than the last few steps alone. The learning rate, the discount and the explore share are the same three knobs the earlier sections introduced, though the trained agent sets them to its own values, and the move scores come from a network that takes 37 readings in and puts out 4 move values.

10 Reward hacking

Reward hacking is when the agent earns the reward without doing what the designer meant. In the boat racing game CoastRunners, an OpenAI agent learned to circle and hit the same targets again and again instead of finishing the race.

The pay becomes the goal

What. Picture the collector paid for getting closer to a yellow banana, stepping closer, then away, then closer, without ever eating.

How. Reward shaping adds extra pay for progress toward the goal. The safe kind also takes the pay back when the agent moves away, so going round a loop earns no net bonus.

Why. When it works, the pay the designer writes matches what the designer meant, and the agent cannot earn by looping.

A reward model is a network trained to score answers the way people would. A chat model trained against such a score can learn replies that please the score more than the people it stands for, as Aligning Language Models with RL shows.

The tool runs in a small practice arena with one yellow banana and a few blue ones; a banana does not come back once eaten, and a clock ends the episode. In this arena the designer pays a small bonus whenever a step brings the agent closer to the yellow banana.

Equation 7. The reward is the only pay the agent hears, so what the designer writes here decides what the agent learns. A delivery company that pays its drivers per delivery faces the same gap: pay for deliveries, and drivers rush; pay for careful driving, and they slow down.

1\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}} = \htmlClass{eqt}{\htmlStyle{color:#b7950b}{\text{yellow}_{t+1}}} - \htmlClass{eqt}{\htmlStyle{color:#2471a3}{\text{blue}_{t+1}}}\)
Intuition. The meant pay counts bananas: yellows add, blues take away. The shaped pay is this pay plus a bonus for progress.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) is the reward after the move at step t, the meant pay. \(\htmlClass{eqt}{\htmlStyle{color:#b7950b}{\text{yellow}_{t+1}}}\) is one when the step ate the yellow banana and zero otherwise, and \(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{\text{blue}_{t+1}}}\) is one when the step ate a blue banana and zero otherwise. The minus sign takes the blue count off the yellow count, so eating a blue banana cancels a yellow one. \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) equals \(\htmlClass{eqt}{\htmlStyle{color:#b7950b}{\text{yellow}_{t+1}}}\) minus \(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{\text{blue}_{t+1}}}\): the meant pay is the yellow count minus the blue count. The shaped pay is this meant pay plus a bonus for progress.
Example. Take a step where the collector eats a yellow banana and no blue one: the meant pay counts that yellow and nothing else.

Intuition. The given pay adds a bonus for progress toward the yellow banana. It is the meant pay, the yellow count minus the blue count, plus a bonus for progress.
The mathematics. \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r^{\text{shaped}}_{t+1}}}\) is the shaped reward, the pay after shaping. \(\htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\) is the meant pay, the yellow count minus the blue count. c is the bonus size, the pay per step closer, and \(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{b_{t+1}}}\) is one when the step brought the agent closer to the yellow banana and zero otherwise. Example. Take a step where the collector eats a yellow banana after stepping closer: the shaped pay counts the banana plus the bonus.
Take a step that brings the collector closer to the yellow banana without eating it. The meant pay is nothing, since no banana was eaten, but the shaped pay adds the progress bonus, so the agent is paid for progress even before it eats. That is the bonus a looping agent games: it can earn the bonus again and again by stepping closer, then away, then closer, without ever eating.

11 Scores, chances or one fixed output

The collector acts on what it senses, not on the full state. What it senses at one moment is an observation: here, the arena’s sensor readings, which can be less than the full state. A spot with a blue banana just out of sight and a spot without one can give the collector the same readings.

Three ways a policy picks a move

What. Picture the banana agent on one spot, comparing its four move scores and playing the tallest bar. A policy can pick a move by scores, by chances, or by one fixed output.

How. A stochastic policy gives each move a chance and draws its move, instead of always playing the same move in the same state. A deterministic policy always plays the same move in the same state. Some agents output one amount every time instead of picking from a list of moves.

Why. When it works, the shape fits the job: scores for the banana agent, chances for a chat model choosing its next word, one fixed output for a robot arm.

The trained banana agent compares move scores and plays the best-scored move. Equation 8 writes the draw down.

12 Choosing what to learn next

Which family of methods should you learn first, and what does each one learn?

Start with Q-Learning. The value methods learn how good each move is; the policy methods learn what to do; the model methods learn how the world works; and the multi-agent methods handle several learners on one floor.
