1 Learning to walk from camera frames

A robot that learns from camera images by trial and error needs a huge amount of real practice, and real practice is slow and costly.

The running example is a walker, a two-legged robot that must learn to walk forward, seen only through a camera. The camera follows the walker from the side as it moves.

The agent is the learner that picks the moves. (RL Basics) A state is the agent’s situation right now; a move, or action, is one choice the agent can make in a state; a reward is the number the world hands back after each move, good or bad. (RL Basics) Here the agent is the program that drives the walker’s joints, turning each camera frame into motor commands. Each camera frame shows the walker’s body and the ground beneath it.

DeepMind Control is a set of simulated robot tasks, such as this walker. An observation is what the agent senses at one moment. (RL Basics) Here the observation is the camera frame. The camera frames are small, low-resolution pictures.

The walker is paid for moving forward while staying upright. A real step is one move made in the real environment, with the reward and the next state it brings. On the walker each real step means running the simulated robot forward and rendering a new camera frame, so real steps are the expensive part. On a physical robot, every real step would also wear its motors a little.

A torque is a turning force a motor applies at a joint. (Continuous-Action RL) A continuous action is a real number, or a list of them, that can take any value in a range, like a torque, instead of one choice from a list. (Continuous-Action RL) So each move is a set of torques, one for each joint, and there is no short list of moves to try. Each leg has a hip, a knee and an ankle, each driven by its own motor.

1.1 The method Dreamer grew from

Dreamer grew from World Models (Ha and Schmidhuber, 2018), an earlier agent that learned a guess of two games and, in one of them, learned to play entirely inside that guess. It is worth a short look, because Dreamer keeps its main idea and fixes its gaps.

A model is the agent’s learned guess of where a move leads and what it pays. (RL Method Families) Latent means hidden: learned by the network rather than observed directly. A world model is a learned model that turns observations into a compact latent state and predicts how that state changes after each action. Dreamer learns the same kind of model from the walker’s camera frames.

CarRacing is a top-down driving game, and VizDoom Take Cover is a first-person game where the player must dodge fireballs. A recurrent network is a network that carries a memory from one step to the next. (RNN Basics) Both games are played from the screen pixels alone.

World Models squeezed each frame into a short list of numbers, called a code, and used a recurrent network to learn how those codes change. On top sat a controller, a tiny network that picks the moves from the code and the memory’s summary of the past. The model’s temperature sets how much randomness it adds when it imagines. In CarRacing the track is new on every try.

World Models was the first known agent to reach the average total reward at which CarRacing counts as solved. In VizDoom the controller was trained only inside the model’s imagined game and still dodged fireballs in the real one; a higher temperature made the dream harder and made tricks that only work in the dream harder to find. In Take Cover the player earns reward for every step it stays alive. In Take Cover, monsters across the room throw fireballs at the player.

1.2 What World Models left open

World Models trained the part that squeezes each frame and the part that predicts the next one first, from random play, and only then the controller on top. Dreamer keeps training its model on new real experience while its behaviour learns.

The controller was trained by trial and error with Covariance Matrix Adaptation Evolution Strategy (CMA-ES), which tries many weight settings and keeps and recombines the best. That ignores the gradients the model could offer, how the reward would change for a slightly different torque, so the controller had to stay tiny; the paper names training through the dream as future work. Dreamer learns its behaviour by gradients through the model, so its networks can be large.

An imagined step is one move tried inside the model; an imagined rollout is a run of them, each starting where the last one ended. (Model-Based RL) Dreamer’s imagined rollouts start from real moments the walker has lived.

A policy is the agent’s rule for choosing a move in each state; it may always pick the same move or pick by chance. (RL Basics) Model exploitation means the policy finds actions where the learned model is wrong and scores well only in imagination. World Models’ controller found moves that made the dream’s fireballs vanish, a trick that failed in the real game. Dreamer also learns its behaviour inside a model, so it faces the same risk.

2 Learning to act by imagining

Dreamer learns a world model too, then trains the walker’s behaviour entirely inside it.

An episode is one run from the start until it ends. (RL Basics) The return is all the reward still to come, with later rewards counted a little less. (RL Basics) A walker that falls early loses all the return it would have earned by walking on.

A state’s value \(V(s)\) is the return the agent expects from state \(s\). (RL Basics) A critic is a second network that guesses each state’s value, the return expected from it. (Actor-Critic) Dreamer’s critic is written \(V_\phi\). The critic lets Dreamer value what lies past the end of a short imagined rollout.

A policy network is a network that looks at the state and outputs the chance of each move. (Policy Gradients) An actor is the policy network that picks the action; the critic’s guesses are used to score how good it was. (Actor-Critic) Dreamer’s actor picks the torques; for amounts like these it gives a range of likely torques instead of a chance per move.

Latent dynamics are the world model’s rules for how the hidden state changes from one step to the next. Learning in imagination means the actor and critic train only on rollouts the world model makes up, while the model keeps learning from real episodes. The actor and critic never see a real frame while they learn; only the model does. Both learn from the same imagined rollouts; this is panel (b) of Figure 1.

The real world gives no gradient: nobody can ask the real world how the reward would change for a slightly different torque. But the learned model is a network, so it can, and the actor learns how a small change in its torques changes all later imagined rewards.

Exploration noise is a small random nudge added to the actor’s actions while it learns, so the agent tries moves it is not sure about. (Training DDPG) Real episodes are collected with this noise added to the actor’s torques.

2.1 Short imagined rollouts with a critic at the end

The planning horizon is how many imagined steps the agent commits to before it looks at the real world again. (Model-Based RL) Dreamer imagines only a short way ahead from each real moment.

The imagination horizon \(H\) is how many steps each imagined rollout runs before a critic values the rest. Here \(H\) counts imagined steps; it is not the curly \(\mathcal{H}\) of the Soft Actor-Critic page. Short H is safe but short-sighted. H is Dreamer’s planning horizon, counted in imagined steps.

Each imagined step starts from the last imagined state, so a small model error grows the further ahead the agent imagines. (Model-Based RL) So the longer Dreamer imagines, the less it can trust the end of the rollout, which is where the critic takes over.

The critic’s value at the rollout’s end stands in for everything after it.

PlaNet, a planner that plans a fresh sequence of actions before every real step, and an actor trained on imagined rewards alone, without a critic, both see reward only inside the horizon. Dreamer imagines these short rollouts from many stored real moments at once.

Rebuild the frame from the hidden state; used only to train the model, never while imagining. \(t\) counts real steps and \(t-1\) is the step before; \(o_t\) the image and \(a\) the torques; the model reads both to update its guess. \(\hat s_t\) the hidden state, random because the model is unsure and keeps several possible states, each with its own chance, so \(p\) and \(q\) give chances over states; \(\omega\) the model’s weights. \(p\) is the guess that sees the frame; every \(q\) predicts from the hidden state alone. The bar reads given: \(q_\omega(o_t \mid \hat s_t)\) is the guess of the frame given the hidden state. Line 2 is the model’s latent dynamics, the only line besides the reward line that imagination needs. This builds on the representation and dynamics lines of MuZero’s model card.

The model is trained on stored real sequences.

An expected value is the average over everything that can happen by chance, weighted by how likely each outcome is. (Probability) The sign \(\mathbb{E}\) marks an expected value. (Probability) The average runs over the stored sequences drawn and the hidden states the model samples.

Equation 2. The model objective. Make the hidden state rebuild the image and predict the reward, with the guess without the image close to the guess with it.
\(\displaystyle \begin{aligned} J_\omega = \mathbb{E}\Big[\sum_t \;&\log \htmlStyle{color:var(--sym-model)}{q_\omega}(\htmlStyle{color:var(--sym-state)}{o_t} \mid \htmlStyle{color:var(--sym-hidden)}{\hat s_t}) \\ &+ \log \htmlStyle{color:var(--sym-model)}{q_\omega}(\htmlStyle{color:var(--sym-reward)}{r_t} \mid \htmlStyle{color:var(--sym-hidden)}{\hat s_t}) \\ &- \htmlStyle{color:var(--sym-discount)}{\beta}\,\mathrm{KL}\big(\htmlStyle{color:var(--sym-model)}{p_\omega} \,\Vert\, \htmlStyle{color:var(--sym-model)}{q_\omega}\big)\Big] \end{aligned}\)
The model is trained to make this as large as possible: the hidden state must rebuild the image and predict the reward, and the guess made without the image must stay close to the one made with it, so imagination can run without images. Row 1 says how well the observation line of the world-model card rebuilds the frame; row 2 says how well the reward line predicts the reward. Row 3 is the Kullback-Leibler (KL) divergence, the gap between the guess with the image and the guess without it, and \(\beta\) is its weight: a larger \(\beta\) keeps the guess without the image closer to the guess with it; a smaller \(\beta\) lets the model lean on the image. Training minimises \(-J_\omega\), the negative of the model objective. This builds on the world-model card above. MuZero’s loss card never rebuilds the image.

The actor and critic then work only on hidden states the model imagines.

The sign \(\sim\) means drawn at random from. (RL Basics) A Gaussian actor outputs one centre and one width per torque and draws each torque from that bell. (Soft Actor-Critic) The reparameterization trick writes a random draw as the centre plus the width times a fixed random number, so the critic’s gradient can flow back into the actor. (Soft Actor-Critic) In Dreamer that gradient comes from the imagined returns, through the model.

Equation 3. The actor and critic. The same actor and critic as Actor-Critic, living on imagined hidden states.
\(\displaystyle \htmlStyle{color:var(--sym-action)}{a_j} \sim \htmlStyle{color:var(--sym-policy)}{\pi}_{\htmlStyle{color:var(--sym-actor)}{\theta}}(\htmlStyle{color:var(--sym-action)}{a_j} \mid \htmlStyle{color:var(--sym-hidden)}{\hat s_j})\)
The same actor and critic as Actor-Critic, living on imagined hidden states. At an imagined walker state, choose torques and judge the state. \(j\) an imagined step, counting from the real moment \(t\); \(\pi_\theta\) the actor, a Gaussian over torques, with a squashing step that squeezes each draw into the joints’ allowed range, sampled with the reparameterization above (code block 1’s rsample(); the paper writes \(q_\phi\)).
\(\displaystyle \htmlStyle{color:var(--sym-statevalue)}{V}_{\htmlStyle{color:var(--sym-statevalue)}{\phi}}(\htmlStyle{color:var(--sym-hidden)}{\hat s_j})\)
\(V_\phi\) the critic (the paper writes \(v_\psi\)). This builds on Actor-Critic’s actor and critic (Actor-Critic).

The page writes \(\hat s\) for the model’s hidden state (the paper writes \(s\)), \(j\) for an imagined step (the paper writes \(\tau\)), \(\omega\) for the world model’s weights (the paper writes \(\theta\); the series keeps \(\theta\) for the actor).

The discount \(\gamma\) sets how much a reward one step later still counts. (RL Basics) Dreamer values each imagined state by mixing short and long sums of imagined reward.

Equation 4. The lambda-return. Mix every choice of how many imagined steps to trust, so no single choice decides the value.
\(\displaystyle \begin{aligned} \htmlStyle{color:var(--sym-statevalue)}{V}_{\htmlStyle{color:var(--sym-lambda)}{\lambda}}(\htmlStyle{color:var(--sym-hidden)}{\hat s_j}) &= \htmlStyle{color:var(--sym-reward)}{\hat r_{j+1}} \\ &\quad + \htmlStyle{color:var(--sym-discount)}{\gamma}(1-\htmlStyle{color:var(--sym-lambda)}{\lambda})\, \htmlStyle{color:var(--sym-statevalue)}{V}_{\htmlStyle{color:var(--sym-statevalue)}{\phi}}(\htmlStyle{color:var(--sym-hidden)}{\hat s_{j+1}}) \\ &\quad + \htmlStyle{color:var(--sym-discount)}{\gamma}\htmlStyle{color:var(--sym-lambda)}{\lambda}\, \htmlStyle{color:var(--sym-statevalue)}{V}_{\htmlStyle{color:var(--sym-lambda)}{\lambda}}(\htmlStyle{color:var(--sym-hidden)}{\hat s_{j+1}}) \end{aligned}\)
The example is the same imagined walker state, valued with short and long trust. One way to value a state is to add the imagined rewards of the next few steps and let the critic value the rest. That is the n-step target of MuZero’s value-target card and Actor-Critic. The lambda-return mixes every such choice of how many steps to trust, so no single choice decides. Each state’s target blends the critic’s value of the next state with the next state’s own target, so the blend carries every horizon length at once. Computed backwards, each state’s target is its next reward plus a blend of the critic’s value of the next state and the next state’s own target, starting from the critic’s value at the rollout’s end. \(\lambda\) between zero and one; near zero leans on the next reward and the critic, near one on the longest imagined sum. This backward form equals the paper’s weighted mix of those step-count choices; at the last imagined step the target is the critic’s value there. The paper counts each state’s own reward in its sums; the page uses the series’ reward index. This builds on the n-step target of MuZero’s value-target card and the Generalized Advantage Estimation (GAE) \(\lambda\) of Actor-Critic, the same mixing idea.

Both networks then learn from these targets.

Equation 5. Learning. Raise the lambda-returns along imagined futures through the model, and teach the critic to predict them.
\(\displaystyle \max_{\htmlStyle{color:var(--sym-actor)}{\theta}}\; \mathbb{E}\Big[\sum_{j=t}^{t+H-1} \htmlStyle{color:var(--sym-statevalue)}{V}_{\htmlStyle{color:var(--sym-lambda)}{\lambda}}(\htmlStyle{color:var(--sym-hidden)}{\hat s_j})\Big]\)
The actor changes its torques to raise the lambda-returns along its imagined futures, with gradients flowing back through the model. The example is many imagined walker rollouts in parallel from a batch of real moments. \(\theta\) actor weights; \(\phi\) critic weights; the sum over \(j\) runs over the same imagined steps as line 1.
\(\displaystyle \begin{aligned} \min_{\htmlStyle{color:var(--sym-statevalue)}{\phi}}\; \mathbb{E}\Big[\sum_{j} \tfrac{1}{2}\,\big(&\htmlStyle{color:var(--sym-statevalue)}{V}_{\htmlStyle{color:var(--sym-statevalue)}{\phi}}(\htmlStyle{color:var(--sym-hidden)}{\hat s_j}) \\ &- \htmlStyle{color:var(--sym-statevalue)}{V}_{\htmlStyle{color:var(--sym-lambda)}{\lambda}}(\htmlStyle{color:var(--sym-hidden)}{\hat s_j})\big)^2\Big] \end{aligned}\)
The critic learns to predict those returns. The target \(V_\lambda\) is held fixed when training the critic (stop-gradient, plain: treated as a label). The world model’s weights \(\omega\) stay fixed during this step, and so do the critic’s while the actor learns. The actor’s line is minimised as its negative. This builds on the actor and critic card and the lambda-return card above, and the critic loss of Actor-Critic.

The sums stop one step before the rollout’s end; the last imagined state only supplies the critic’s value that starts the lambda-return.

5 Dreamer in PyTorch

The imagination step, the lambda-return and the two losses; the world model’s own training, which raises the model-objective card, is a standard sequence-model loop and is left out. start holds hidden states of a batch of real moments from line 1 of the world-model card.

def imagine(start, actor, transition, reward, H):
    s = start.detach()
    states, rewards = [s], []
    for _ in range(H):
        a = actor(s).rsample()
        s = transition(s, a).rsample()
        states.append(s)
        rewards.append(reward(s).mean)
    return torch.stack(states), torch.stack(rewards)
  1. states holds H + 1 states, the start first; rewards[i] is the reward after the action taken at states[i], the \(\hat r_{j+1}\) of the lambda-return card; rsample() draws the torques and the next hidden state so gradients pass through both draws (line 2 of the world-model card, and the actor and critic card), and the reward line gives its mean. detach() cuts the start state off from the gradients, so the rollout starts from a fixed hidden state; torch.stack gathers the per-step states and rewards into one list each.
def lambda_return(rewards, values, gamma, lam):
    R = values[-1]
    out = []
    for i in reversed(range(len(rewards))):
        R = rewards[i] + gamma * ((1 - lam) * values[i + 1] + lam * R)
        out.append(R)
    return torch.stack(out[::-1])
  1. R starts as the critic’s value at the rollout’s end; each step pairs a reward with the value of the state after it; reversing at the end puts out[i] beside states[i]. lam is the \(\lambda\) of the lambda-return card, the mix weight; values holds the critic’s value of each state.
frozen = list(world_model.parameters()) + list(critic.parameters())
for p in frozen:
    p.requires_grad_(False)
S, Rw = imagine(start, actor, world_model.transition, world_model.reward, H)
targets = lambda_return(Rw, critic(S), gamma, lam)
actor_loss = -targets.mean()
actor_opt.zero_grad(); actor_loss.backward(); actor_opt.step()
for p in frozen:
    p.requires_grad_(True)
critic_loss = 0.5 * (critic(S[:-1].detach()) - targets.detach()).pow(2).mean()
critic_opt.zero_grad(); critic_loss.backward(); critic_opt.step()
  1. Line 1 of the learning card as a loss to minimise (the minus sign), then line 2 on the same states except the last; freezing the parameters still lets the actor’s gradient flow through the model’s and critic’s computations, but writes no gradient into their weights. world_model is the world model of the world-model card, here used for its transition and reward lines; actor_opt updates the actor’s weights, and critic_opt updates the critic’s weights.

6 A critic at the horizon

The walker is reactive, meaning a good move pays almost at once, so it copes without a critic. The paper’s no-critic version and PlaNet succeed only on reactive tasks like it, so the tool uses Hopper Hop, a task the paper names where the payoff comes many steps later. On Hopper Hop the robot must crouch first, and only the hop after it pays. The critic has learned from earlier imagined rollouts that a crouched pose is worth a lot, because a hop usually follows it.

In this tool the hop pays only after the longest horizon on the knob. In the paper’s per-task curves at horizon 20, the version without a critic fails on Hopper Hop.

7 Dreamer in practice

Training runs in rounds. Each round takes many training steps, and each step updates all three networks at once: the model trains on a batch of real sequences, then the actor and critic learn from imagined rollouts starting from every state in the batch. Then the actor plays one real episode with exploration noise, and that episode joins the dataset of all real episodes.

A longer \(H\) sees further ahead, but it leans on a model that grows less accurate the further it imagines. A higher \(\lambda\) trusts longer imagined sums of reward, while a lower one trusts the critic sooner. A larger action repeat, how many frames one chosen move is held for, makes each imagined step cover more real time.

Dreamer needed no slow-moving copy of the critic to build its targets (the target network of Training DDPG) and no extra reward for staying undecided. For tasks that can end early, the model also predicts whether the episode continues and weights later steps by it. While the actor learns, the world model and the critic stay frozen.

The learning rate \(\eta\) sets how big a step each update takes. (RL Basics) Dreamer uses a separate learning rate for the model, the actor and the critic.

7.1 Walking and balancing from pixels on DeepMind Control

Each seed is one full training run started from a different random start. A distributed agent runs many copies that play in parallel and feed one learner. A model-free method learns values or a policy straight from real steps, with no model of the world. (RL Method Families) The paper compares four agents on the same tasks.

Dreamer passed the best model-free agent’s average with far fewer real steps.

The paper’s horizon study shows Dreamer with its critic holding up across imagination horizons, while without the critic, and for PlaNet, results depend on the horizon.

8 Control from pixels with few real steps

Dreamer fits when the actions are amounts, the observations are images, and real steps are scarce.

Against MuZero, which searches through possible moves at decision time: no search at decision time, so acting is cheap; continuous actions work directly.

Against D4PG, the strongest model-free agent in the paper’s comparison: similar or better total reward from far fewer real steps and, in the paper’s report, less total training time; the cost is a model to tune.

10 When the world learns back

Apart from AlphaZero’s and MuZero’s board games, where the opponent was a copy of the same learner, each learner so far faces a world that does not learn back.

What changes when the world contains another learner? Multi-Agent Reinforcement Learning takes that step, with Self-Play DDPG and MADDPG.
