1 The benchmark

Every design in this series was judged on one benchmark, the ImageNet Large Scale Visual Recognition Challenge (ILSVRC) classification task: 1,000 classes and about 1.2 million training images [1]. Top-5 error is the share of test images whose true class is not among the model's five best guesses; top-1 error uses only the best guess. Because the benchmark stayed fixed, each design's fix can be compared with the others.

2 BatchNorm in this series

From 2015 on, the networks here train with batch normalization after each convolution: each channel is normalized over the batch, with stored averages at test time. Batch Normalization teaches how, and why it fails with one or two images per GPU.

3 Same compute, different blocks

A convolution's cost grows with its kernel size and with its channels in and out:

The rule each design works around.
\(\displaystyle {\text{cost} \propto \htmlClass{eqt sym-slice}{\htmlStyle{color:var(--sym-slice)}{k}}^2\,\htmlClass{eqt sym-mean}{\htmlStyle{color:var(--sym-mean)}{C_{\text{in}}}}\,\htmlClass{eqt sym-var}{\htmlStyle{color:var(--sym-var)}{C_{\text{out}}}}}\)
A \(k \times k\) convolution does about \(k^2\) times \(C_{\text{in}}\) times \(C_{\text{out}}\) multiply-adds at every output pixel, where \(k\) is the kernel size and \(C_{\text{in}}\), \(C_{\text{out}}\) are the channels in and out.
So a big kernel is expensive, and shrinking \(C_{\text{in}}\) before it is cheap. CNN Basics has the full count.

Give one stage of a network a compute budget and let each design spend it on its own block. For the same compute, each later design buys more layers or more branches.

The 5×5 column stands for AlexNet's second layer, the 3×3 column for VGG's stacks, the Inception column for one module with its four branches, and the bottleneck for ResNet-50's block, which shrinks channels with a 1×1 layer, runs the 3×3, and expands again.
