A model-based agent learns, or is given, a model of the world. It plans or practices inside that model, and acts in the real world to collect steps that improve the model, the policy or both (Figure 1). The methods in Value-Based RL, Policy Gradients: REINFORCE, Actor-Critic and PPO and Continuous-Action Actor-Critic: TD3 and SAC learn from real steps only; they are model-free.

1 Dyna

A chess player tries moves in their head before touching a piece; a model lets an agent do the same before spending real steps.

A model predicts the next state and reward from a state and a move; planning uses it to look ahead or practice without the real world. Dyna (Sutton 1991) runs the Q-learning update from Value-Based RL on imagined steps as well as real ones.

A real step into the goal teaches one square; the model lets the agent replay the square before it without moving (Figure 2).

This is the Dyna-Q update: the same Q-learning update as Value-Based RL; the model only supplies extra steps to apply it to.
target = r + γ · max Q(s′, a′)
Q(s, a), the Q-value, is the future reward expected from move a in state s. r is the reward the step earned, 1 for the step into the goal. max Q(s′, a′) is the best score over every move a′ in the next state s′. γ, the discount, shrinks that future score for the delay, 0.95 in the book’s maze.
Q(s, a) ← Q(s, a)
+ α · (target − Q(s, a))
α, the learning rate, 0.1 here, moves the score that fraction of the way toward the target (the arrow means replace with). Together: the real step gives the square next to the goal 0.1, and a replay then carries value one square further back, 0.0095 (Figure 2). Builds on the Q-learning card of Value-Based RL; Dreamer in Section 3 is the other way to use a model.

Dyna-Q adds n imagined steps from a remembered model after each real one (Sutton and Barto’s RL textbook, 2018, section 8.2). The code runs one Dyna-Q step on the book’s 6 by 9 maze. env_step(s, a) is the maze’s rule, returning (r, s_next).

import random
import numpy as np

alpha, gamma, eps, n = 0.1, 0.95, 0.1, 5   # book's maze
Q = np.zeros((54, 4))   # 6 x 9 squares, 4 moves
model = {}              # (s, a) -> (r, s_next)
GOAL = 8                # top-right square, episode ends

def q_update(s, a, r, s_next):
    future = 0.0 if s_next == GOAL else Q[s_next].max()
    Q[s, a] += alpha * (r + gamma * future - Q[s, a])

def dyna_step(env_step, s):
    if random.random() < eps:
        a = random.randrange(4)
    else:
        a = int(random.choice(np.flatnonzero(Q[s] == Q[s].max())))
    r, s_next = env_step(s, a)
    q_update(s, a, r, s_next)
    model[(s, a)] = (r, s_next)
    for _ in range(n):
        (s_m, a_m), (r_m, s_m_next) = random.choice(list(model.items()))
        q_update(s_m, a_m, r_m, s_m_next)
    return s_next
  1. 1Sets the book’s maze values, the Q-table, an empty model and the goal square.
  2. 2The Q-learning update, line 2 of the Q-learning card above, with no future past the goal.
  3. 3Picks a move ε-greedily, the best-scoring move (ties at random) except for a small chance ε of a random one, and takes one real step.
  4. 4Learns from the real step and stores it in the model.
  5. 5Replays n imagined steps, each a stored step picked at random (the book picks a seen state, then a move tried there); n is the count that varies in Figure 3.

Each imagined step can carry value, a square’s best Q, one square further back from the goal, so the reward found there spreads through the maze without new real steps (the RL textbook, Example 8.1). Where a square has no value yet, all four moves there score 0 and the agent picks one at random; once value reaches the start, following the best move from each square gives a route to the goal. Reaching the goal ends an episode, and the agent starts again from the start.

Until the goal is first found every value is 0, so imagined steps change nothing and every n takes the same real steps to find it, on average. After that, a larger n forms the route in fewer real steps on average, at the cost of n + 1 updates per real step, and n = 0 is plain Q-learning, where each real step updates only the square it left. One random run can occasionally flip that order.

In the book’s averaged runs a good route took about 25, 5 and 3 episodes for n = 0, 5 and 50. Imagined steps matter most when real steps are slow or costly, as for a robot. DQN’s experience replay reuses stored real steps the same way, with a network in place of the table.

2 AlphaZero and MuZero

AlphaZero (Silver et al. 2018) uses a game’s rules for a tree search, a look-ahead over move sequences that a network steers, and learns from games against itself.

In one Go position the network’s first guesses are rough; 100 search visits sharpen them (Figure 4).

This is the AlphaZero loss: the search turns the network’s guesses into better move chances, and training makes the network match the search and the final result, so the next search starts better.
(p, v) = f(s)
From a position s, one network f gives p, a probability for each move, and v, the predicted result: 0.6, 0.3, 0.1 and 0.2 in Figure 4. The rules produce each next position. The search tries moves with high p, few visits and a high average v so far, and scores each position where a line stops with v instead of playing the game to the end.
π(a) ∝ N(a)
N(a) counts how often the search tried move a from the current position, and π is those counts scaled to probabilities (∝ reads “in proportion to”): visits 70, 25 and 5 of 100 give 0.70, 0.25 and 0.05. The move played is drawn from π or is its most visited move.
loss = (z − v)2 − π · log p
z is the game’s final result, −1 for a loss, 0 for a draw, +1 for a win. The first term is a squared gap to a target, as in the critic loss on Policy Gradients, here the real result: 0.64 in Figure 4. The second adds over moves the search’s chance times the network’s log chance (natural log; the categorical cross-entropy), where · multiplies move by move and adds; it is smallest when p matches π: 0.77, against 0.75 if they matched. The paper adds weight decay. Together: one loss teaches value and move chances from self-play. Builds on Dyna’s use of a model to plan ahead and on the return and the value of RL Basics; the MuZero card, next, repeats this loss at each unrolled step.

MuZero (Schrittwieser et al. 2020) learns the model instead. MuZero is not told the rules of Go; it must also predict what each move pays (Figure 5).

This is the MuZero loss. MuZero learns its own rules inside a hidden state, a list of numbers the network makes up, so its loss is the AlphaZero loss at the root and at each of the 5 unrolled steps, plus a reward term at each unrolled step.
h0 = repr(observation)
repr, the representation network, turns what the agent sees, here the board, into h0: the first label in Figure 5.
(r, hk+1) = dynamics(hk, a)
The dynamics network stands in for the rules: from hidden state hk and move a, it predicts the reward and the next hidden state; the second label, a predicted reward of 0.2 where the real reward was 0.
(p, v) = f(hk)
The AlphaZero network read from the hidden state: the third label. The hidden state only has to predict rewards, moves and values, never to redraw the board.
loss = Σk [ℓ(uk, rk)
+ ℓ(zk, vk) + ℓ(πk, pk)]
MuZero replays a stored game and unrolls the dynamics 5 moves along the moves really played. ℓ is an error between a target and a prediction: squared error for reward and value in board games, the cross-entropy for p (the MuZero paper). The sum over the steps k pulls each predicted reward toward the reward u really seen, each value toward the observed return, and each p toward the search’s π at that step: one step’s loss is 1.45 in Figure 5. Together: the three predictions the search needs, trained together. Builds on the AlphaZero card; Dreamer, next, also learns a model but trains an actor and critic in it.

3 World Models and Dreamer

Builds on actor-critic methods (Policy Gradients: REINFORCE, Actor-Critic and PPO, section 2)

World Models (Ha and Schmidhuber 2018) train a small controller inside a learned model of the game, then run it for real. Making the model’s predictions more random kept the controller from exploiting the model’s errors. An agent that counts only the reward inside a fixed window of imagined steps turns shortsighted. Dreamer (Hafner et al. 2020) learns a compact hidden-state model from replayed experience and trains its actor and critic on imagined runs inside it; the critic estimates the reward past the window, so the actor still aims for rewards that come later.

Dreamer’s walker practices inside its own model of the body, a few steps at a time (Figure 6).

The reward 1 comes when it reaches walking speed; γ is 0.9, as in the return strip of RL Basics.

This is the imagined return: add the rewards the model imagines over a short window, then let the critic’s guess stand in for everything after it.
return = r0 + γ r1
+ … + γH−1 rH−1 + γH v(sH)
The model imagines H steps ahead and predicts a reward rk at each; γk discounts it as in the discounted return of RL Basics. γH v(sH) is the critic’s guess for every reward past the window: rewards 0, 0 and 1 and the critic’s 2 make 2.27 in Figure 6, against 0.81 without the critic. This is the k-step estimate of the Dreamer paper (section 4, eq. 5); Dreamer then averages such estimates over several window lengths (eq. 6) and trains the actor to raise it. Together: the return of RL Basics, cut after H steps and finished by the critic, as in the n-step return figure of Policy Gradients, section 2. Builds on the MuZero card’s learned model rolled forward on hidden states and on the critic of actor-critic methods; it is the last card on this page.

The methods in this series ran on small examples such as a cliff walk, CartPole and a maze. What does it take to train one on a real agent, a banana collector that sees 37 sensor numbers? Deep Q-Networks (DQN) builds that agent with replay, a target network and the Double and Dueling changes from Value-Based RL.
