In the racing game Enduro, on an empty road it hardly matters which way you steer; what matters is how good the road ahead is. Can a network learn how good the road is once, instead of once for every way to steer?

The agent is the learner that picks the moves, as taught in RL Basics. A state is the agent's situation right now; a move, or action, is one choice the agent can make in a state; a reward is the number the world hands back after each move, good or bad, as taught in RL Basics. Here the agent is a program driving in Enduro.

Most of the time the road ahead is empty, and the car only has to keep going.

In Enduro the state is the screen, a move is a steering or speed press, and the reward is points for passing cars.

Each car passed adds to its points, and a crash slows the car down.

An episode is one run from the start until it ends, as taught in RL Basics. Enduro is an Atari game, one of the classic home video games, where you race and pass other cars. Each episode is one race against the clock.

The car keeps passing cars until time runs out.

Steering on an empty road

The return is all the reward still to come, with later rewards counted a little less, as taught in RL Basics. A policy is the agent's rule for choosing a move in each state; it may always pick the same move or pick by chance, as taught in RL Basics. On an empty road the return hardly depends on which way the car steers.

A state's value \(V(s)\) is the return the agent expects from state \(s\), as taught in RL Basics. A move's value \(Q(s,a)\), also called its score, is the return the agent expects if it makes move \(a\) in state \(s\) and plays on from there, as taught in RL Basics. So on an empty road every move's score is almost the road's value \(V\).

A Q-table keeps one score for every state and move, as taught in Q-Learning. A Q-network is a neural network that takes the state and outputs one score per move, in place of the table, as taught in Deep Q-Networks. The discount \(\gamma\) sets how much a reward one step later still counts, as taught in RL Basics. No table could list every road screen, so a network reads the screen instead.

Q-learning's target is the step's reward plus the discounted best score in the next state, as taught in Q-Learning. Training a Q-network with Q-learning's target is a Deep Q-Network, DQN for short. The car earns points only when it passes another car, so most targets are just the discounted best next score.

A head is the last layer of a network, the one that outputs a quantity. A plain DQN has one head with one output per move. In many states, like an empty road, the move barely matters.

In a network with one head, an update changes only the played move's output directly, and the layers below the head move too; the state's worth is not learned as one shared number, so it is relearned move by move. The gaps between the moves' scores are tiny next to the state's worth, so a small error in the network's guesses can reorder the moves.

The dueling network keeps the shared layers that read the screen and replaces the one head with two streams, each a small stack of layers; a plain DQN is then called a single-stream network. One stream will learn how good the road is, the other how much each steering press adds.

Each stream ends in its own head; the value head outputs one number for the state, and the other head one number per move, what that move adds. On an empty road the per-move head's numbers stay near zero, and the value head carries almost all of each move's score.

Value plus advantage

A move's advantage is how much better it is expected to do than the usual result from that state. The per-move head described above is called the advantage head, because it outputs each move's advantage. The greedy policy plays the top-scored move in each state, as taught in Q-Learning. On an empty road every move's advantage is near zero; with a car just ahead, the move that passes it has the largest.

A move's advantage says how much better it is than the state's usual worth under the policy the car follows. Averaged over the moves the policy picks, the advantages come to zero, so a move that is better than usual must balance a move that is worse. Under the greedy policy the best move is the usual result itself, so its advantage is zero and every other move's is zero or below.

A move's advantage is how much better or worse it is than the state's usual worth. \(A\) is the advantage, \(Q\) the move's score and \(V\) the state's worth.
\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}}) = \htmlClass{eqt}{\htmlStyle{color:#196f3d}{V}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}) + \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{A}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}})\)
So each move's score is the state's worth plus what the move adds. On an empty road every \(A\) is near zero and \(Q\) is almost all \(V\).

How the value and advantage streams combine

Adding the heads plainly does not pin the split down: add a fixed amount to \(V\) and take it from every \(A\), and every move's score stays the same. So the network subtracts the mean advantage, the average over all moves, before it adds \(V\) back.

\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}}) = \htmlClass{eqt}{\htmlStyle{color:#196f3d}{V}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}) + \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{A}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}})\)
The plain join adds the heads, but it is not well defined, because \(V\) up and every \(A\) down by the same amount leaves \(Q\) unchanged. \(V\) comes from the value head and \(A\) from the advantage head.
\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\bar{A}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}) = \tfrac{1}{\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\lvert\mathcal{A}\rvert}}}\sum_{\htmlClass{eqt}{\htmlStyle{color:#a04000}{b}}} \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{A}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{b}})\)
This is the average advantage over all moves. \(\lvert\mathcal{A}\rvert\) is the number of moves, \(b\) runs over every move, and the bar means average.
\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}} = \htmlClass{eqt}{\htmlStyle{color:#196f3d}{V}} + \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{A}} - \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\bar{A}}}\)
Subtracting the average keeps the moves in order and makes training steadier, and it is the version used in practice. \(V\) is then the state's worth with an unknown fixed amount added or taken away, so \(V\) no longer means the state's exact worth, and the mean subtraction trades \(V\)'s exact meaning for steadier training.

Subtracting the max instead would give the best move an advantage of exactly zero, as in Value plus advantage above; subtracting the mean shifts every score by the same amount, so the best move's advantage is no longer exactly zero, but training is steadier.

\(\arg\max\) picks the move whose score is largest, as taught in RL Basics. To steer, the car needs only the advantage stream's argmax.

Every training step changes \(V\), because every move's score contains \(V\).

In Enduro the paper's saliency maps, pictures of which pixels an output depends on most, show the value stream watching the road and the horizon, while the advantage stream reacts only when a car is right ahead. So the value stream learns from every screen, even on an empty road.

A pass through the dueling network

The live network is the Q-network being trained, with weights \(\phi\), as taught in Deep Q-Networks. Replay keeps a memory of past steps, and training draws random batches from it, as taught in Deep Q-Networks. So the network keeps learning from stretches of road it drove long ago, not only from the newest one.

A remembered step is written \((s, a, r, s')\), the prime meaning next; on the earlier pages these were \((s_t, a_t, r_{t+1}, s_{t+1})\).

A value head, an advantage head and a mean subtraction

A dueling network shaped like the one in my repo.

self.shared = nn.Sequential(nn.Linear(N_READINGS, HIDDEN), nn.ReLU(), nn.Linear(HIDDEN, HIDDEN), nn.ReLU())
self.v = nn.Sequential(nn.Linear(HIDDEN, HIDDEN), nn.ReLU(), nn.Linear(HIDDEN, 1))
self.a = nn.Sequential(nn.Linear(HIDDEN, HIDDEN), nn.ReLU(), nn.Linear(HIDDEN, N_MOVES))
  1. 1The shared layers read the screen.
  2. 2The value stream ends in a head with an output for the state.
  3. 3The advantage stream ends in a head with an output per move.

The forward pass joins the streams.

def forward(self, s):
    h = self.shared(s)
    v, a = self.v(h), self.a(h)
    return v + a - a.mean(1, keepdim=True)
  1. 1The forward pass takes the screen in.
  2. 2The shared layers read the screen, then each stream reads those features.
  3. 3The mean advantage is subtracted before \(V\) is added back.

The target network is a slow copy of the Q-network, with weights \(\phi'\), that computes the targets, as taught in Deep Q-Networks. Double DQN's target lets the live network pick the next move and the target network score it, as taught in Double DQN. The dueling network changes only the head, so its target is built exactly as Double DQN builds it.

A batch is a handful of remembered steps trained on together; the loss averages how far their scores are from their targets, as taught in Deep Q-Networks. The car's network still learns from remembered stretches of road against a slow copy.

Training reuses the Double DQN target unchanged, written out in full.

with torch.no_grad():

The value stream carrying the road

With many moves, the dueling network learns the move scores sooner than a single-stream one.

The tool's road is a simple made-up one whose true move scores are known, so the chart can show how far each network's scores still are from them. With many moves, the extras are near copies of the four named moves, so even with a car ahead many moves score almost the same.

Only the head changes

Training a dueling network works exactly like training a DQN; only the network's head changes. The shared layers read the screen, then a value stream and an advantage stream, each ending in a head, combine inside forward(), and training uses the Double DQN loss unchanged.

The learning rate \(\eta\) sets how big a step each update takes, as taught in RL Basics. My repo trains a dueling network on my banana collector, an agent that senses a square arena through sensor readings. My repo keeps the paper's split into a value head and an advantage head, with smaller layers and its own inputs.

When splitting value from advantage helps

Splitting value from advantage helps when there are many moves with similar scores, or many states where the move does not matter, as in driving, where most moves do almost nothing. It combines freely with Double DQN and prioritized replay, and it costs a small extra head.

Learning the move directly

So far every page has scored moves and then picked the best. The next pages learn the move directly.
