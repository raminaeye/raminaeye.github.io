ADC Fundamentals

How a voltage becomes numbers, and how fine those numbers are.

An electrode gives an analog voltage, which can take any value in a range, but a computer stores only integers. The ADC (analog-to-digital converter) turns each voltage sample into an integer code, and without knowing how it does that you will misread every neural signal you record.

Microvolts (millionths of a volt) go in and integer codes come out, because the ADC samples in time and rounds in amplitude.

An analog-to-digital converter (ADC) measures a voltage at a fixed rate and outputs each measurement as a whole number, a code. Three choices shape it: the voltage range its codes cover, how many codes it has, and how fast it samples. Range and code count set the smallest change it can see and the noise its rounding adds, which is what this page works through; the sampling rate is the next page.

An ADC turns a wave into numbers

What the ADC measures

Every ADC has a reference voltage, Vref, that sets the top and bottom of what it can measure. The ADC is differential (it measures the difference between its two inputs), so a span of 2.4 V reads from −1.2 V to 1.2 V. Anything beyond saturates, and the output flatlines at its maximum code.

Quantization rounds the voltage to the nearest code: a ramp goes in, a staircase comes out, and each stair step is one LSB (Least Significant Bit), the voltage width of one step. The resolution, B bits, sets how many steps fit in the range; together with Vref it sets the smallest detectable change.

How many codes B bits give.
codes = 2B
The code count is 2 multiplied by itself B times, B being the number of bits. Each bit doubles the count, because it splits every existing code in two, so the count goes 2, 4, 8 and on. At 10 bits that is 1,024 codes, numbered 0 to 1,023, and one more bit gives 2,048.

Bit depth decides how fine the stairs are, and that sets your quantization noise floor (the level of rounding noise sitting under the signal), measured as the signal-to-noise ratio (SNR).

The sampling rate has its own failure, aliasing, and its own fix, the anti-alias filter in front of the ADC. Both live on Aliasing and Anti-Aliasing Filters.

How fine the steps are

The ADC staircase

When the input is a ramp, the ADC output is a staircase. More bits make finer stairs and a smaller gap between the steps and the signal.

More bits make finer stairs that hug the signal.

How wide one stair step is

In volts, one LSB is the full span divided by the number of codes. At ±1.2 V and 10 bits that is 2.34 mV per code. A wider Vref stretches each step; more bits shrink every step.

How wide one stair step is.
LSB = 2·Vref2B
The codes spread evenly over the full span from −Vref to +Vref, which is 2Vref wide, so one step is that span divided by the code count 2B. Each extra bit halves the step, and a larger Vref widens it.

At 10 bits a 100 µV neural spike fills under a twentieth of one step, so the ADC cannot see it.

One sample, four steps

One conversion shifts, scales, rounds and clips a voltage to give its code. A toy 3-bit ADC over ±1.2 V reading a fixed 0.42 V shows each step.

The code the sample lands on, and the rounding error left behind.
code = round(Vin − VminLSB)
Subtracting Vmin = −Vref moves the bottom of the range to zero, and dividing by the LSB counts how many steps up the sample sits. Rounding picks the nearest quantization level (one of the 2B voltages a code stands for), and the clip to 0 to 2B − 1 is saturation, so any voltage past a rail gets the end code.
e = Vin − Vcode
The error is the gap between the sample and the voltage of its level. Rounding to the nearest level keeps it within half a step either way, unless the input sat past a rail (an end of the input range) and was clipped.

Two voltages converted to codes in NumPy. The two code lines are the card's shift, divide, round and clip; volts go in, and codes and rounding errors come out, with 1.5 V clipped to the top code.

import numpy as np

V_REF, B = 1.2, 10                 # V_ref and B from the cards
lsb = 2 * V_REF / 2**B
v_in = np.array([0.42, 1.5])       # 1.5 V is past the rail

code = np.round((v_in + V_REF) / lsb)
code = np.clip(code, 0, 2**B - 1)
v_rung = -V_REF + code * lsb
error = v_in - v_rung              # e in the card
print(code, error)

Rounding error becomes the noise floor

Rounding to the nearest code leaves a quantization error of at most half an LSB either way, even on a perfect noiseless signal. On a slow ramp the error is a sawtooth from −½ LSB to +½ LSB that resets at every step crossing.

On a real signal those sawtooth cycles fall out of phase and blur into noise: zero average, every value in the range about equally likely. That is a uniform random variable, so its variance (how spread out the errors are) is the LSB squared over twelve:

How big the rounding noise is.
variance = LSB212
When the input is equally likely to land anywhere within a step, the error is spread evenly over one LSB, and an even spread of width LSB has variance LSB²/12. The noise floor therefore depends only on the step size, not on the signal.
σq = LSB√12
σq, the standard deviation, is the square root of that variance, the typical size of one error, about 0.29 LSB. It scales with the step, so halving the LSB halves it.

A check of the LSB²/12 rule on 100,000 random voltages at 8 bits, drawn below the top level so none saturates. The errors stay within about ±0.5 LSB, and the variance ratio printed last comes out near 1.0.

import numpy as np

V_REF, B, N_SAMPLES = 1.2, 8, 100_000
lsb = 2 * V_REF / 2**B
rng = np.random.default_rng(0)
v_in = rng.uniform(-V_REF, V_REF - lsb, N_SAMPLES)

code = np.round((v_in + V_REF) / lsb)
error = v_in - (-V_REF + code * lsb)
print(error.min() / lsb, error.max() / lsb)
print(error.var() / (lsb**2 / 12))
Max |error| = 0.5 LSB (always)
σq = LSB/√12

Finer steps, the same sawtooth error, and the same flat histogram of how often each error occurs.

Each extra bit adds 6.02 dB of SNR

The signal-to-noise ratio (SNR) compares signal power to noise power, in decibels:

SNR in decibels.
SNR = 10·log10(PsignalPnoise) dB
Psignal and Pnoise are the signal and noise powers, and their ratio says how many times stronger the signal is. The logarithm, log10, turns ratios into equal steps, so every tenfold rise in the ratio adds 10 dB and a ratio of a million is just 60 dB.

For a full-scale sine wave (one that swings across the whole range the ADC can measure), that ratio works out to a famous rule of thumb:

The best SNR a B-bit ADC reaches on a full-scale sine.
SNR = 6.02B + 1.76 dB
Each extra bit halves the step, which halves the noise voltage and quarters the noise power, a gain of 6.02 dB per bit. The 1.76 dB comes from the sine's shape, because a full-scale sine's power over the rounding noise is 1.5 × 22B, and 10 log10 1.5 = 1.76. Ten bits give about 62 dB.

A sine half a step inside full scale, quantized at 10 bits. The SNR is the mean signal power over the mean error power, and it prints about 62 dB, as 6.02 B + 1.76 predicts.

import numpy as np

V_REF, B, N_SAMPLES = 1.2, 10, 100_000
FREQ = 0.01234                      # cycles per sample
lsb = 2 * V_REF / 2**B
amp = V_REF - lsb / 2
sig = amp * np.sin(2 * np.pi * FREQ * np.arange(N_SAMPLES))

code = np.clip(np.round((sig + V_REF) / lsb), 0, 2**B - 1)
quant = -V_REF + code * lsb
p_signal = np.mean(sig**2)
p_noise = np.mean((sig - quant)**2)
print(10 * np.log10(p_signal / p_noise))
SNR = 61.96 dB
Noise voltage = halves each bit
6.02 dB for each bit, on a 1.76 dB base

Each bit stacks one more 6.02 dB block.

Gain magnifies the signal and shrinks the window

Neural signals are tens to hundreds of times smaller than the ADC's 2.34 mV step, so wired straight in they read as zero. The amplifier multiplies the electrode voltage by a constant gain. At 250x one code covers 9.375 μV at the electrode, but the window that fits between the ±1.2 V rails shrinks by the same factor, a clipping risk.

Gain multiplies the voltage, so at the electrode the step and the window shrink by the same factor.
Vamp = gain × Vel
The amplifier multiplies the electrode voltage Vel by a constant gain to give Vamp, the voltage the ADC sees, which must stay within the ±1.2 V rails. The larger the gain, the smaller the electrode voltage that already reaches a rail.
electrode LSB = ADC LSBgain
Every electrode voltage arrives gain times bigger, so one ADC step covers a slice that many times smaller at the electrode. At a gain of 250 the 2.34 mV step covers 9.375 µV at the electrode.
electrode input range = ±Vrefgain
Dividing the rails by the same gain gives the electrode input range. Raising the gain shrinks the step and the input range together, so a finer step always comes with a bigger risk of clipping.

The gain card in numbers. Dividing by GAIN turns the 2.34 mV ADC step into 9.375 µV at the electrode and the ±1.2 V rails into a ±4.8 mV input range.

V_REF, B, GAIN = 1.2, 10, 250

lsb_adc = 2 * V_REF / 2**B
lsb_electrode = lsb_adc / GAIN
window = V_REF / GAIN              # electrode side, volts
print(lsb_adc, lsb_electrode, window)

ADC sees 1.0 mV

More gain magnifies a 1 mV spike and shrinks the electrode input range at the same rate, until the spike clips.

At the ADC input the range stays ±1.2 V whatever the gain. Adding bits splits it into finer steps; only a smaller reference voltage shrinks the range itself.

Three converters trade speed, precision and power

Flash compares the voltage against every level at once, with one comparator (a circuit that reports which of two voltages is larger) per level. It is the fastest, but the comparators multiply with the bits, so it stays at low bit depths and drinks power.

SAR (successive-approximation register) finds one bit per higher-or-lower question: three questions for eight levels. It sits in the middle, fast enough, fine enough and low power.

Sigma-delta samples far faster than it needs to and averages the noise away: slow, but extremely fine. A feedback loop keeps a running sum (sigma) of the difference (delta) between its coarse output and the input, which pushes the rounding noise up to high frequencies where the averaging removes it. It is the oversampling idea from Aliasing and Anti-Aliasing Filters taken to its limit.

The SAR search as a function, run on the 3-bit sample from One sample, four steps. Each pass of the loop asks one higher-or-lower question and appends one bit, so sar(0.42) returns 5, binary 101.

def sar(v_in, v_ref=1.2, B=3):
    lsb = 2 * v_ref / 2**B
    lo, hi = -v_ref - lsb / 2, v_ref - lsb / 2  # half-step shift
    code = 0
    for _ in range(B):
        mid = (lo + hi) / 2
        bit = int(v_in >= mid)
        code = 2 * code + bit
        if bit:
            lo = mid
        else:
            hi = mid
    return code

print(sar(0.42))

In short, bit depth sets how many codes you get, and together with Vref that gives you the LSB, the size of each stair step. Gain is what shrinks the electrode LSB down to microvolts so tiny neural signals don't get lost between steps. Quantization error is stuck at half a step no matter how clean your signal is, and each extra bit adds 6.02 dB of SNR.

A one-second tone stored as 16-bit codes and read back with SciPy. wavfile.read returns the rate and the int16 codes, and the last line turns them into floats between −1 and 1.

import numpy as np
from scipy.io import wavfile

FS, TONE_HZ, FULL_SCALE = 16000, 440, 32768
t = np.arange(FS) / FS
tone = 0.5 * np.sin(2 * np.pi * TONE_HZ * t)
codes = np.round(tone * (FULL_SCALE - 1)).astype(np.int16)
wavfile.write("tone.wav", FS, codes)

rate, read_back = wavfile.read("tone.wav")
print(rate, read_back.dtype)           # 16000 int16
signal_float = read_back.astype(np.float64) / FULL_SCALE

Gotchas

  • 8-bit WAV codes are unsigned, 0 to 255, so subtract 128 before scaling.
  • Float WAV files are not clipped; values past ±1 come back as stored.
  • Convert codes to float before arithmetic; sums of int16 values overflow.
