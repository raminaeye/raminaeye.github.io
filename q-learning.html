A robot that only knows how good each spot is still cannot pick a step unless it knows where every step leads. How can it choose well without that?

The agent is the learner that picks the moves, as taught in RL Basics. A state is the agent's situation right now; a move, or action, is one choice the agent can make in a state; a reward is the number the world hands back after each move, good or bad, as taught in RL Basics. Here the agent is a warehouse robot that must reach its charging dock. It starts in one bottom corner and the dock sits in the other. The floor is a grid of cells, one per place the robot can stand. It knows only which cell it stands in, not where each move leads or what it costs.

An episode is one run from the start until it ends, as taught in RL Basics. The ledge is the strip of floor between the start and the dock. Sutton and Barto's textbook calls the ledge a cliff and the dock the goal. Reaching the dock can take many moves.

Each move's reward is minus the battery it uses, so the best total is the one closest to zero. Every move costs a little battery; stepping onto the ledge costs a lot and puts the robot back at the start; only reaching the dock ends the episode. The cheapest way to the dock is the shortest path that never steps onto the ledge.

Scores for moves, not just for places

A move is only worth making if what follows it is worth having. The return is all the reward still to come, with later rewards counted a little less, as taught in RL Basics. A state's value \(V(s)\) is the return the agent expects from state \(s\), as taught in RL Basics. A policy is the agent's rule for choosing a move in each state; it may always pick the same move or pick by chance, as taught in RL Basics. On this floor every value is below zero, because every step costs battery.

Knowing how good a spot is does not yet say which step to take. A model is the agent's learned guess of where a move leads and what it pays, as taught in RL Method Families. A move's value \(Q(s,a)\), also called its score, is the return the agent expects if it makes move \(a\) in state \(s\) and plays on from there, as taught in RL Basics. Epsilon-greedy usually plays the top-scored move and, with chance \(\epsilon\), a random one instead, as taught in RL Basics. From a cell away from the walls, each of the four moves leads to a different neighbouring cell.

Best play is the policy that earns the most return; \(Q^{*}\) is each move's value under it, as taught in RL Basics. The robot learns these scores only from its own steps, one cell at a time.

RL Basics taught how to improve a cell's value \(V(s)\). To choose a move from \(V\) alone, the robot would need to know where each move leads, which is a model it does not have. A score for each move, \(Q(s,a)\), lets it choose by comparing scores, with no model at all. And it wants the scores of best play, not of whatever it happens to do now.

A table of move scores

A Q-table keeps one score for every state and move. Here, one row per cell and one column per move, every entry a guess of \(Q\). A tabular method stores one entry per state, or per state and move. So a step only ever changes the one entry it played.

A target is the value the current score is pulled toward. The discount \(\gamma\) sets how much a reward one step later still counts, as taught in RL Basics. Just above the dock, the step down is worth only minus the cost of that last step.

An expected value is the average over everything that can happen by chance, weighted by how likely each outcome is, as taught in Expected value and RL Basics. The sign \(\mathbb{E}\) marks an expected value, as taught in Probability. On this floor the average hardly matters, because the same move from the same cell always has the same result.

Take the robot in the cell just above the dock. Best play is to step down onto the dock, and that move's score is minus the cost of that last step.

The star marks best play, reminded above the card. When the move ends the episode, nothing follows and only the reward counts.

The best-play score of a move is that worth averaged over what the floor does after the move. \(\mathbb{E}\) is the expected-value sign reminded just above the card; here it averages over what the floor does by chance. The bar with \(s_t, a_t\) reads ‘after move \(a_t\) in cell \(s_t\)’.

On this floor that makes the best scores climb toward zero as the cells get closer to the dock.

Aiming every score at best play

Bootstrapping means putting your own current guess for the next state inside the target, as taught in RL Basics. The TD (temporal difference) error \(\delta\) is how much one step surprised the agent, the target minus the current guess, as taught in RL Basics. A fall sends the robot back to the start, so it must walk the whole floor again.

The learning rate \(\eta\) sets how big a step each update takes, as taught in RL Basics. The robot steps along an aisle toward the dock and pays a little battery; it judges that move by its reward plus the best it believes it can do from the new cell.

\(\arg\max\) picks the move whose score is largest, as taught in RL Basics. The greedy policy plays the top-scored move in each state. While the scores are still guesses, the top entry can point the wrong way, and the next steps correct it.

\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#196f3d}{y_t}} = \htmlClass{eqt}{\htmlStyle{color:#7d6608}{r_{t+1}}}\)
The target starts with what this step paid. \(r_{t+1}\) as in the card above.
\(\displaystyle \qquad +\; \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\gamma}} \max_{\htmlClass{eqt}{\htmlStyle{color:#a04000}{a}}} \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_{t+1}}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}})\)
It then adds the best score in the cell the robot reached, unless the episode ended. \(Q\) without the star is the table's current guess; there is no average because it is one step. \(\max_{a} Q(s_{t+1},a)\) is the top entry in the next cell's row, the max in the target, which assumes best play from there whatever the robot will really do. At the dock the episode ends and this line is left out, so the target is the step's reward alone. A fall is not an ending; the robot pays the big cost, goes back to start and the episode goes on, so a fall keeps this line.
\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#b03a2e}{\delta_t}} = \htmlClass{eqt}{\htmlStyle{color:#196f3d}{y_t}} - \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}})\)
The TD error is the target minus the current guess. \(\delta_t\) is the TD error, reminded above the card.
\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}}) \leftarrow \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s_t}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a_t}}) + \htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\eta}}\, \htmlClass{eqt}{\htmlStyle{color:#b03a2e}{\delta_t}}\)
Only the entry for the cell and move just played is nudged. The arrow reads “replace with”. \(\eta\) is the learning rate from the sentences above the card; raising it is faster and jumpier when costs vary, lowering it steadier and slower. Every other entry stays.
\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\pi_{\text{greedy}}}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}) = \arg\max_{\htmlClass{eqt}{\htmlStyle{color:#a04000}{a}}}\, \htmlClass{eqt}{\htmlStyle{color:#8e44ad}{Q}}(\htmlClass{eqt}{\htmlStyle{color:#2471a3}{s}}, \htmlClass{eqt}{\htmlStyle{color:#a04000}{a}})\)
The policy it ends up with plays the top-scored move in each cell. \(\arg\max_a\) and \(\pi_{\text{greedy}}\) are the argmax and the greedy policy from the sentences above the card. While learning, the robot plays epsilon-greedy around it, as reminded above.

The target never uses the move epsilon-greedy will pick next, only the best one, so random exploring moves change which steps arrive but not what the target aims at; that is why the table ends at best-play scores. Off-policy means learning the values of one policy while playing another. Q-learning is off-policy, since it learns best play while it plays epsilon-greedy.

A table, a max and a nudge after every step

Gymnasium is a library of ready-made practice worlds. The code below runs on Gymnasium's CliffWalking-v1, which is this floor. The table comes first, then the move choice.

import gymnasium as gym
import numpy as np

env = gym.make("CliffWalking-v1")
Q = np.zeros((env.observation_space.n, env.action_space.n))
n_moves = env.action_space.n
GAMMA = 1.0
LR = 0.5
EPSILON = 1.0
rng = np.random.default_rng(0)
  1. 1Make the floor and an all-zero table with one row per square and one column per move. Every score starts at zero; the section on starting scores, below, explains why that matters on this floor.
  2. 2The discount, the learning rate and the exploring chance, with the values the settings table lists, and the random draw the moves use.

The move choice is epsilon-greedy.

def act(s, eps):
    if rng.random() < eps:
        return int(rng.integers(n_moves))
    return int(np.argmax(Q[s]))
  1. 1Epsilon-greedy picks a random move with chance eps.
  2. 2Otherwise it picks the top-scored move in the row.

After every move, the update is two lines.

y = r if terminated else r + GAMMA * Q[s_next].max()
Q[s, a] += LR * (y - Q[s, a])
  1. 1The target. Here r is \(r_{t+1}\), the step's reward, and s_next is \(s_{t+1}\), the next cell.
  2. 2The Q-learning update, nudging the played entry toward its target.

Then the loop that runs the robot, episode after episode.

eps = EPSILON  # fixed here; later on this page it shrinks
for episode in range(200):
    s, info = env.reset()
    terminated = False
    while not terminated:
        a = act(s, eps)
        s_next, r, terminated, truncated, info = env.step(a)
        if terminated:
            y = r
        else:
            y = r + GAMMA * Q[s_next].max()
        Q[s, a] += LR * (y - Q[s, a])
        s = s_next
  1. 1Each episode starts at the start square and runs until the dock.
  2. 2Each step plays a move, and the floor answers with a reward and the next square. terminated is true only at the dock, and this floor is never cut off, so truncated never ends it.
  3. 3The update from the block above, then move on to the next square.

How the starting scores steer the robot

Starting every score at zero is hopeful when every real score is below zero, because moves not yet tried then look best. The robot's route is the path its best moves trace from the start, drawn as arrows in the tool below; it counts only if it reaches the dock without a loop. A gloomy start puts every score far below any real score; once one route reaches the dock its scores rise above all the others, so the robot can keep that first route even when a shorter one exists.

The tool below runs the robot from each start, so the two routes can be compared. Hatched cells still have a move the robot has not tried, and grey cells are still at the gloomy start.

Updating after every step, and exploring less over time

Q-learning updates after every step, while the episode is still going. It learns online, from a stream of moves, and never has to store whole episodes or wait for them to end. There is no batch of steps to gather and no network to train.

The table is a NumPy array, indexed by cell and move. Every score starts at zero, as How the starting scores steer the robot explains. Only reaching the dock ends the episode, so only that step uses the step's reward alone.

After each episode the robot can shrink \(\epsilon\) by a decay factor \(\kappa\), so it explores a lot early and mostly plays its top-scored move late.

\(\displaystyle \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\epsilon}} \leftarrow \max(\htmlClass{eqt}{\htmlStyle{color:#2c3e50}{\kappa}}\, \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\epsilon}},\ \htmlClass{eqt}{\htmlStyle{color:#0e6b59}{\epsilon_{\min}}})\)
After each episode epsilon shrinks a little, but never below a set minimum. \(\kappa\) is the decay factor from the sentence above, just under one (code EPS_DECAY); closer to one explores longer. \(\epsilon_{\min}\) is the minimum (code EPS_MIN), so the robot never stops trying.

In code, the shrink happens at the end of each episode.

eps = max(EPS_MIN, eps * EPS_DECAY)

Within the tool's short run a gloomy start can lock in the first route it finds, while the guarantee in Table 3 needs every move tried often enough.

When a table is enough

A table is enough when the cells are few and the moves are short to list, so every entry is tried often. When a mistake made while exploring is costly, prefer SARSA, which learns the safer path while the robot is still trying things.

Where Q-learning falls short

When exploring next to the ledge is costly, SARSA learns a path that stays safe while the robot is still trying things. When there are too many states for a table, Deep Q-Networks keeps this page's target and update but swaps the table for a neural network. When scores run high, Double DQN lets a second set of scores judge each pick.
