Layer Normalization and RMSNorm

Each token is normalized over its own features. RMSNorm keeps the rescaling and drops the centering.

1 Big picture

BatchNorm needs a batch. In an RNN its statistics would differ at every time step, and in a transformer they would mix sequences of different lengths and their padding. Ba et al.'s LayerNorm normalizes over the features of one example instead, so the computation is identical in training and at test time [1].

LayerNorm runs on every forward pass, once per token, twice in every block of GPT-2 and LLaMA style transformers, and it carries no state between steps. Use LayerNorm in transformers and RNNs; use RMSNorm, its cheaper variant, when the norm's cost matters, as in LLMs.

2 LayerNorm

Run the recipe on one token's own \(d\) numbers, where \(d\) is the hidden size.

The mean and spread over one token's numbers, then normalize, then scale and shift.
\(\displaystyle {\htmlClass{eqt sym-mean}{\htmlStyle{color:var(--sym-mean)}{\mu}} = \dfrac{1}{d}\sum_{k=1}^{d} x_k}\)
The token's own mean over its \(d\) features.
\(\displaystyle {\htmlClass{eqt sym-var}{\htmlStyle{color:var(--sym-var)}{\sigma^2}} = \dfrac{1}{d}\sum_{k=1}^{d}(x_k - \htmlClass{eqt sym-mean}{\htmlStyle{color:var(--sym-mean)}{\mu}})^2}\)
Its spread around that mean.
\(\displaystyle {\htmlClass{eqt sym-hat}{\htmlStyle{color:var(--sym-hat)}{\hat{x}_k}} = \dfrac{x_k - \htmlClass{eqt sym-mean}{\htmlStyle{color:var(--sym-mean)}{\mu}}}{\sqrt{\htmlClass{eqt sym-var}{\htmlStyle{color:var(--sym-var)}{\sigma^2}} + \htmlClass{eqt sym-eps}{\htmlStyle{color:var(--sym-eps)}{\epsilon}}}}}\)
Center and scale the token. A token whose numbers have all grown by the same factor comes out the same.
\(\displaystyle {y = \htmlClass{eqt sym-gain}{\htmlStyle{color:var(--sym-gain)}{\gamma}} \odot \htmlClass{eqt sym-hat}{\htmlStyle{color:var(--sym-hat)}{\hat{x}}} + \htmlClass{eqt sym-gain}{\htmlStyle{color:var(--sym-gain)}{\beta}}}\)
A learned scale and shift per feature; \(\odot\) means multiply feature by feature. These four lines together are LayerNorm.
The shared recipe with the slice set to one token. Nothing here depends on other tokens or on the batch, so training and inference compute the same thing.

\(\gamma\) and \(\beta\) have one value per feature, so after normalization the features can still differ in scale. In a recurrent network the statistics are computed separately at each time step, from that step's summed inputs alone [1].

3 LayerNorm, not BatchNorm, for tokens

Picture a padded batch of sentences going into a transformer [5]. The two layers average over different cells:

BatchNorm's batch mean mixes other sentences and padding tokens into each token's statistics, so a token's output depends on what else is in the batch and on how much padding it holds. BatchNorm also depends on the batch size and must switch to stored averages at inference, so training and inference differ. LayerNorm uses only the token's own numbers, so neither problem exists.

4 RMSNorm

In an LLM the norm runs twice per block for every token, so its cost adds up. Zhang and Sennrich's hypothesis: the re-centering is dispensable and the re-scaling does the work [2]. RMSNorm divides by the root mean square, the typical size of the features, and subtracts nothing.

Keep the rescaling, drop the centering.
\(\displaystyle {\begin{aligned}&\htmlClass{eqt sym-var}{\htmlStyle{color:var(--sym-var)}{\mathrm{RMS}(x)}} = \\ &\quad \sqrt{\tfrac{1}{d}\textstyle\sum_{k} x_k^2 + \htmlClass{eqt sym-eps}{\htmlStyle{color:var(--sym-eps)}{\epsilon}}}\end{aligned}}\)
The typical size of the features, with no mean subtracted.
\(\displaystyle {y = \htmlClass{eqt sym-gain}{\htmlStyle{color:var(--sym-gain)}{\gamma}} \odot \dfrac{x}{\htmlClass{eqt sym-var}{\htmlStyle{color:var(--sym-var)}{\mathrm{RMS}(x)}}}}\)
Divide by it and apply the learned gain; there is no shift.
Compared line by line with LayerNorm's card, the mean line and \(\beta\) are gone, and the spread is measured around zero instead of around the mean.

The paper writes RMS without \(\epsilon\); PyTorch adds \(\epsilon\) inside the root and defaults it to the machine epsilon of the input's number type [6]. Across the paper's models, RMSNorm matched LayerNorm's quality while running faster [2]. LLaMA uses RMSNorm [3].

5 LayerNorm and RMSNorm on one token

The line that runs at the current step is lit.
\(\displaystyle {\begin{aligned}&\text{LayerNorm: } x_k - \htmlClass{eqt sym-mean}{\htmlStyle{color:var(--sym-mean)}{\mu}} \\ &\htmlClass{eqt sym-mean}{\htmlStyle{color:var(--sym-mean)}{\mu}} = \dfrac{1}{d}\sum_{k} x_k\end{aligned}}\)
LayerNorm moves the token's center to zero. RMSNorm skips this step.
\(\displaystyle {\begin{aligned}&\text{LayerNorm: } \dfrac{x_k - \htmlClass{eqt sym-mean}{\htmlStyle{color:var(--sym-mean)}{\mu}}}{\sqrt{\htmlClass{eqt sym-var}{\htmlStyle{color:var(--sym-var)}{\sigma^2}} + \htmlClass{eqt sym-eps}{\htmlStyle{color:var(--sym-eps)}{\epsilon}}}} \\ &\text{RMSNorm: } \dfrac{x_k}{\htmlClass{eqt sym-var}{\htmlStyle{color:var(--sym-var)}{\mathrm{RMS}(x)}}}\end{aligned}}\)
Both divide by a size: the spread around the mean, or the root mean square around zero.
\(\displaystyle {\begin{aligned}&y = \htmlClass{eqt sym-gain}{\htmlStyle{color:var(--sym-gain)}{\gamma}} \odot \htmlClass{eqt sym-hat}{\htmlStyle{color:var(--sym-hat)}{\hat{x}}} \\ &\quad (+\,\htmlClass{eqt sym-gain}{\htmlStyle{color:var(--sym-gain)}{\beta}} \text{ for LayerNorm})\end{aligned}}\)
The learned per-feature gain, and LayerNorm's shift.

6 What centering adds

Drag the round handle to shift every feature of the token up or down, and the square handle sideways to stretch them. LayerNorm and RMSNorm agree when a token's features are centered; they differ by the mean RMSNorm keeps.

7 Where it sits in a transformer

Modern LLMs put the norm before each sublayer (Pre-LN), which trains without a long learning-rate warmup [4]; The Transformer Block explains why.

9 In practice

nn.LayerNorm(d, eps=1e-5): the default eps is 1e-5, and a larger one smooths near-constant tokens. elementwise_affine turns \(\gamma\) and \(\beta\) on or off, and bias=False (PyTorch 2.1 or later) keeps \(\gamma\) without \(\beta\). nn.RMSNorm(d) needs PyTorch 2.4 or later; its eps=None means the machine epsilon of the input's type [6].

B, T, d = 32, 10, 512
x = torch.randn(B, T, d)                     # a batch of token vectors
ln_mean = x.mean(dim=-1)                     # LayerNorm's mean: per token, shape (B, T)
bn_mean = x.mean(dim=(0, 1))                 # BatchNorm's mean: per feature, shape (d,)
ref = (x - x.mean(-1, keepdim=True)) / torch.sqrt(x.var(-1, unbiased=False, keepdim=True) + 1e-5)
ln = nn.LayerNorm(d)                         # gamma starts at ones, beta at zeros
assert torch.allclose(ln(x), ref, atol=1e-5)
class RMSNorm(nn.Module):                    # LLaMA-style
    def __init__(self, d, eps=1e-6):
        super().__init__(); self.eps = eps
        self.weight = nn.Parameter(torch.ones(d))
    def forward(self, x):
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps) * self.weight
rms = nn.RMSNorm(d, eps=1e-6)
assert torch.allclose(RMSNorm(d)(x), rms(x), atol=1e-5)
