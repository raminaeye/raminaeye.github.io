SimSiam: Simple Siamese Representation Learning

One network, two views, a predictor and a gradient stop, and nothing else, and it still learns.

1 The collapse problem, in one page

With no negatives to push against, one output for every image matches every pair and says nothing: that is collapse. In a subtler dimensional collapse, the embeddings spread along only a few directions of the space and stay flat along the rest; Failure Modes and Checks plots it.

The full collapse story is on BYOL: Bootstrap Your Own Latent, which also states the pattern all three methods share: every target side sits behind a stop-gradient.

2 SimSiam shows a stop-gradient and a predictor are enough

SimSiam (Simple Siamese networks, Chen and He 2021; Siamese means two branches with the same weights) uses one network for both views, with no momentum encoder and no negatives. As in BYOL, each view gives an output \(z\) and a prediction \(p\), and each prediction is compared with the other view’s output behind a stop-gradient, written \(\operatorname{sg}\).

Both views through the shared encoder

One network reads both views. The same weights serve both sides, so there is no copy to keep in step.

View 1 predicts, view 2 stays fixed

View 1’s prediction is compared with view 2’s output, held fixed behind the stop-gradient.

The views swap

Now view 2 predicts and view 1 stays fixed. Each view is once the predictor and once the fixed target.

SimSiam’s loss asks each view’s prediction to point the same way as the other view’s output, with that output held fixed.
\(\displaystyle D(\htmlStyle{color:#7d3c98}{p}, \htmlStyle{color:#1f618d}{z}) = -\cos (\htmlStyle{color:#7d3c98}{p}, \htmlStyle{color:#1f618d}{z})\)
\(D\) is the negative cosine similarity, at its lowest when two vectors point the same way and at its highest when they point opposite ways. Lowering it turns \(p\) toward \(z\), and only direction counts, as with BYOL’s unit vectors.
\(\displaystyle \htmlStyle{color:#2c3e50}{L} = \frac{1}{2}D(\htmlStyle{color:#7d3c98}{p_{1}}, \htmlStyle{color:#c0392b}{\operatorname{sg}}(\htmlStyle{color:#1f618d}{z_{2}}))\)
\(L\) takes half of \(D\) for view 1’s prediction against view 2’s output. \(\operatorname{sg}\) treats its contents as a constant, so gradients flow only through the prediction. The network can move its prediction toward the other view’s output but cannot move that output toward the prediction, which removes the easy path where both sides drift together to one constant.
\(\displaystyle + \frac{1}{2}D(\htmlStyle{color:#7d3c98}{p_{2}}, \htmlStyle{color:#c0392b}{\operatorname{sg}}(\htmlStyle{color:#1f618d}{z_{1}}))\)
The second half swaps the views, so each view is once the predictor and once the fixed target.

Removing the predictor collapses it too (0.1%). The SimSiam paper compares training to k-means clustering, which holds cluster centers fixed while fitting points, then updates the centers; the stop-gradient does the job of the fixed-centers step.

3 One SimSiam training step, in code

A SimSiam step has no target network; z.detach() is the stop-gradient \(\operatorname{sg}\) of Section 2 eq lines 2 and 3.

import torch
import torch.nn as nn
import torch.nn.functional as F

def D(p, z):
    return -F.cosine_similarity(p, z.detach(), dim=-1).mean()

online = nn.Sequential(nn.Flatten(), nn.Linear(3 * 32 * 32, 256))   # stand-in
predictor = nn.Linear(256, 256)
x1, x2 = torch.rand(64, 3, 32, 32), torch.rand(64, 3, 32, 32)
z1, z2 = online(x1), online(x2)
p1, p2 = predictor(z1), predictor(z2)
L = D(p1, z2) / 2 + D(p2, z1) / 2
  1. 1\(D\) of Section 2 eq line 1, with detach() as \(\operatorname{sg}\).
  2. 2One network gives outputs \(z\) and predictions \(p\) for both views.
  3. 3Eq lines 2 and 3, each view once predictor and once fixed target.

4 When to use SimSiam

Use SimSiam to pretrain when there is no big batch and no second network to maintain, and as the minimal baseline other methods are compared against.

In the field, the pretrained backbone is fine-tuned end to end for object detection on COCO with Mask R-CNN (Table 5). The same table also reports VOC object detection and COCO instance segmentation.

SimSiam is one network that fits a typical 8-GPU machine, so a small lab can pretrain without the batch or the target copy BYOL needs.

SimSiam runs every training step. It carries only the weights, no target network and no center, and updates nothing after the step.

5 Failure modes and tips

No stop-gradient. Cause: the stop-gradient is removed. Symptom: the probe falls to 0.1% and the output spread falls to zero (Figure 2). Fix: put the stop-gradient back on the target side.

No predictor. Cause: the predictor is removed. Symptom: the probe falls to 0.1%. Fix: put the predictor back, trained, on the online side.

Tip: watch the spread. The output spread (Figure 2) is the diagnostic, so check it early. If the spread falls to zero, the stop-gradient is the first thing to check, since the predictor alone does not hold collapse off.
