Split every convolution into a cheap spatial step and a cheap channel step, then build a phone-sized network from the split.

1 Why a phone network must be cheap

ResNet-50 holds 25.6 million weights and needs 4.09 GFLOPs, billions of multiply-add operations, per image. MobileNetV2 holds 3.5 million weights, needs 0.30 GFLOPs per image. ImageNet is a labeled 1,000-class photo set; top-1 accuracy is the share of test photos whose highest-scoring class is right. SSDLite object detection uses the split. The split is architecture, not a training rule: the blocks run on every forward pass, in training and at test time, carrying only learned weights.

2 Depthwise separable convolution (MobileNet)

A standard kernel filters space and mixes channels in one step. MobileNet (Howard et al. 2017) builds a whole network from this depthwise separable convolution, an idea used earlier by Sifre (2014) and in Xception (Chollet 2017).

2.1 Depthwise and pointwise steps

The depthwise step gives every input channel its own 3×3 kernel. The pointwise step is a 1×1 convolution, which blends the channels at each pixel (1×1 convolution, in Inception (GoogLeNet) and 1×1 Convolutions). In PyTorch, with ci and co the input and output channel counts, groups=ci is what makes dw depthwise: 

import torch
from torch.nn import Conv2d
from functools import partial

Conv = partial(
    Conv2d, bias=False)
ci, co = in_channels, out_channels
opts = dict(padding=1, groups=ci)
dw = Conv(ci, ci, 3, **opts)
pw = Conv(ci, co, 1)
x = torch.randn(batch, ci, height, width)
y = pw(dw(x))
print(y.shape)
# [batch, co, height, width]
D = dw.weight.numel() # dw weights
P = pw.weight.numel() # pw weights
  1. 1The depthwise step \(D\): one 3×3 kernel per channel.
  2. 2The pointwise step \(P\): a 1×1 that mixes the channels.
  3. 3Runs both in order on the input map.
  4. 4Counts the weights of \(D\) and \(P\), which Section 2.2 turns into a formula.

2.2 Weight count of the split

Weights of a standard convolution against its depthwise separable split.
\(\displaystyle \htmlStyle{color:#2471a3}{\text{standard}} = C_{\text{out}} \cdot C_{\text{in}} \cdot k^{2}\)
With \(C_{\text{in}}\) input channels, \(C_{\text{out}}\) output channels and kernel size \(k\), a standard convolution gives every output channel a \(k\) by \(k\) kernel over every input channel.
\(\displaystyle \htmlStyle{color:#a04000}{D} = C_{\text{in}} \cdot k^{2}\)
\(D\) keeps one \(k\) by \(k\) kernel per input channel and never mixes channels.
\(\displaystyle \htmlStyle{color:#a04000}{P} = C_{\text{out}} \cdot C_{\text{in}}\)
\(P\) is a 1×1 convolution from \(C_{\text{in}}\) to \(C_{\text{out}}\) channels; it does all the mixing.
\(\displaystyle \htmlStyle{color:#a04000}{\text{separable}} = \htmlStyle{color:#a04000}{D} + \htmlStyle{color:#a04000}{P}\)
The split counts weights for space and for channels separately, adding two counts instead of multiplying. At \(k\) = 1 the split costs more, so 1×1 layers are never split.

3 MobileNetV2 inverted residual

MobileNetV2 (Sandler et al. 2018) builds its block from the same split convolution and adds a ResNet-style shortcut around it, so the block adds its input back to its output (ResNet and Residual Connections).

① A 1×1 widens the narrow input \(t\) times, to the middle width, so the next layer has many channels to work on.

The block’s output is its input plus three layers applied in turn.
\(\displaystyle h = t \cdot C_{\text{in}}\)
The wide middle holds \(t\) times the input channels. \(h\) is the middle width, \(t\) the expansion ratio, \(C_{\text{in}}\) the input channels, the same \(C_{\text{in}}\) as the weight-count card in Section 2.
\(\displaystyle \htmlClass{eqt}{\htmlData{k=sc}{\htmlStyle{color:#a04000}{y = x +}}} \htmlClass{eqt}{\htmlData{k=p}{\htmlStyle{color:#1f618d}{P}}}(\htmlClass{eqt}{\htmlData{k=d}{\htmlStyle{color:#7d3c98}{D}}}(\htmlClass{eqt}{\htmlData{k=w}{\htmlStyle{color:#7d3c98}{E}}}(x)))\)
\(E\) expands the channels \(t\) times with a 1×1, \(D\) is the depthwise step of Section 2 on the wide map, \(P\) projects back to the input width with no activation, and the shortcut adds the input \(x\).
purple: wide layers \(E\) and \(D\)blue: narrow endsorange: shortcut

Raising the expansion ratio \(t\) gives the depthwise filter more channels at proportionally more cost; \(t\) = 1 skips the widening 1×1. The paper and torchvision use \(t\) = 6 in every stage but the first. The last 1×1 has no ReLU (which keeps positive values and sets negative ones to zero; Convolution, in CNN Basics), because a ReLU on the narrow output would erase information, and the shortcut is used only when the stride (the step between kernel positions; Size, stride and padding, in CNN Basics) is 1 and the width is unchanged.

In PyTorch, branch builds \(P\)(\(D\)(\(E\)(\(x\)))) with ReLU6, a ReLU capped at 6. 

import torch
import torch.nn as nn
from torch.nn import Conv2d
from functools import partial

Conv = partial(Conv2d, bias=False)
BN = nn.BatchNorm2d

def branch(c, t):
    h = c * t  # wide middle
    # groups=h: depthwise 3×3
    dw = Conv(h, h, 3, 1, 1, 1, h)
    return nn.Sequential(
        Conv(c, h, 1), BN(h),
        nn.ReLU6(),
        dw, BN(h), nn.ReLU6(),
        Conv(h, c, 1), BN(c))

class InvRes(nn.Module):
    def __init__(self, c, t=6):
        super().__init__()
        self.f = branch(c, t)

    def forward(self, x):
        return x + self.f(x)

x = torch.randn(batch, channels, height, width)
print(InvRes(channels)(x).shape)
# [batch, channels, height, width]
  1. 1The middle width, \(t\) times the input channels.
  2. 2Widens with a 1×1, the first tall bar of Figure 4.
  3. 3Filters the wide map depthwise, the second tall bar.
  4. 4Projects back to \(c\) channels with no ReLU.
  5. 5Adds the shortcut around the whole branch.

The positional arguments of Conv are in, out, kernel, stride, padding, dilation and groups. BN is batch norm (Batch Normalization).

4 Shrinking a MobileNet with width and resolution

A phone maker ships the same network as a big model and a smaller phone model, shrinking it two ways: thin every layer with the width multiplier \(\alpha\), and shrink the input image with the resolution multiplier \(\rho\). Alpha here is the MobileNet width multiplier; EfficientNet reuses the letter for its depth base.

\(\alpha\) = 1 is the baseline, with typical settings 1, 0.75, 0.5 and 0.25. The paper sets \(\rho\) by the input side: 224, 192, 160 or 128.

Thinning every layer and shrinking the image with two multipliers.
\(\displaystyle \htmlStyle{color:#2471a3}{C_{\text{in},\alpha}} = \alpha \cdot C_{\text{in}}\)
The width multiplier \(\alpha\) scales the input channels of every layer; \(C_{\text{in}}\) is the input channels, the same symbol as in Section 2, where the paper writes \(M\).
\(\displaystyle \htmlStyle{color:#a04000}{C_{\text{out},\alpha}} = \alpha \cdot C_{\text{out}}\)
\(\alpha\) scales the output channels of every layer too, so the whole network thins at once; the paper writes \(N\).
\(\displaystyle \htmlStyle{color:#7d3c98}{S_{\rho}} = \rho \cdot S\)
The resolution multiplier \(\rho\) scales the input image side, so every feature map shrinks with it. \(S\) is the input image side; the paper writes the feature map side \(D_F\).

5 When the split pays, and when it does not

A separable layer saves little. Symptom: the weight count barely moves. Cause: few output channels, or a 1×1 kernel, where the split has nothing to save. Fix: use a standard convolution, as MobileNet does for its first layer and 1×1 layers.

Accuracy drops after the narrow projection. Symptom: accuracy falls right after the block narrows. Cause: a ReLU on the low-channel output discards information. Fix: no activation on the projection, as in section 3.

Depthwise layers stacked with nothing between them. Symptom: channels never mix, however deep the stack. Cause: a depthwise layer only filters each channel on its own; only the pointwise step combines channels (MobileNet paper section 3.1 and Table 1). Fix: always put a pointwise step between depthwise layers.

A depthwise layer that is not depthwise. Symptom: the layer runs fine but costs far more weights than the split should. Cause: Conv2d leaves groups at 1 unless told otherwise, so every output reads every input and the layer is a standard convolution; the shape still works, so nothing errors. Fix: pass groups equal to the input channels, as in section 2.

The blocks are cheap, but how does a block decide which channels to trust? Squeeze-and-Excitation answers that.
