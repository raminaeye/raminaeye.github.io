Non-negative Matrix Factorization (NMF)

Splitting non-negative data into parts that only add.

Non-negative matrix factorization (NMF) writes a non-negative data matrix, such as a spectrogram, as a few non-negative templates times how strongly each is used, so the parts can only add.

NMF iterates on one whole matrix. In supervised use the templates are learned beforehand from clean examples of each sound (Section 7.1), and only the activations are fitted for each new recording.

1 A spectrogram as templates times activations

A spectrogram is a grid whose rows are frequencies and whose columns are short time slices, and each cell says how loud that frequency is at that moment. Each column is a mix of a few spectral templates, each turned up or down over time. NMF is matrix factorization with non-negative factors, the same idea recommender systems use with user and movie factors.

Take an illustrative spectrogram with 4 frequency bins and 3 frames, with a low note in frame 1, a high note in frame 2 and both in frame 3, as when two piano keys are played one after the other and then together. This is how NMF tells which note sounds when in a music recording, and which part of a noisy recording is speech (Section 7).

On a real spectrogram \(W\) and \(H\) together hold far fewer numbers than \(V\), which forces the templates to be shared.

Every frame is built by adding a few spectral templates, each scaled by how loud it is at that moment, and nothing can be subtracted.
\(\displaystyle V \approx W H\)
Each column of \(V\) is \(W\) times the same column of \(H\). In Figure 1, frame 3 uses both templates fully, so it is template 1 plus template 2.
\(\displaystyle V, W, H \ge 0\)
Every entry of all three is zero or positive, so a template can be turned up or switched off but never subtracted.
\(V\) the data, a magnitude spectrogram, \(M\) frequency bins by \(N\) frames.\(W\) the templates, one column per sound, each a spectrum; \(M\) by \(K\).\(H\) the activations, one row per template, how loud it is in each frame; \(K\) by \(N\).\(K\) the rank, the number of templates, much smaller than \(M\) and \(N\), which forces sharing; 2 in Figure 1.≥ 0 the only assumption NMF makes, with no statistics about the sources (Anushiravani 2016, p. 43, the audio-editing thesis Section 7 follows); it is what makes the templates read as parts (Section 2).

\(W\) and \(H\) are unknown; Section 3 scores a guess.

2 Why non-negative gives parts

Builds on the k-means loop (k-Means Clustering, section 2)

With no subtraction allowed, blocks cannot cancel each other, so each block must look like a real piece of the data (Lee and Seung 1999). PCA is computed with the SVD, whose blocks may be negative. Figure 2 takes the SVD of \(V\) as it is, without PCA's subtraction of each bin's mean. Vector quantization goes the other way; like k-means, each frame takes exactly one block, winner takes all. NMF sits between, a few blocks per frame that only add.

Both fits are exact with 2 blocks, but the SVD builds the high note from block 1 minus block 2, a low-minus-high contrast, while NMF's blocks are the two notes themselves.

3 Squared error and KL divergence

Builds on KL divergence (KL Divergence, section 2)

Before \(W\) and \(H\) are known, the fit starts from a rough guess, two templates that each lean toward one note, with every activation the same. Its rebuild is equally loud in every cell, and the two costs below score how far that is from \(V\).

Both count how far the rebuilt spectrogram is from the real one, cell by cell. Squared error punishes big misses most, wherever they are. KL compares ratios, so a quiet bin that is off by a factor counts too, which suits audio magnitudes; the thesis uses KL (eq 4.25, p. 44).
\(\displaystyle \operatorname{SE} = {\sum_{ij} \left(V_{ij} - (WH)_{ij}\right)^{2}}\)
Each miss is squared, so the cells where \(V\) is 0, which the guess misses most, cost far more than cells 1 and 2, which it misses by a little.
\(\displaystyle \operatorname{KL} = \sum_{ij} \Big[ {V_{ij} \log \frac{V_{ij}}{(WH)_{ij}}} - {V_{ij}} + {(WH)_{ij}} \Big]\)
The quiet cell 2 costs more than the loud cell 1, since the same miss is a bigger ratio when the cell is quiet. The two costs are on different scales, so their totals are never compared.
\(\sum_{ij}\) adds over every cell, every bin \(i\) and frame \(j\); on this page \(\Sigma\) is always a sum.\((WH)_{ij}\) the rebuilt value in bin \(i\), frame \(j\).\(\left(V_{ij} - (WH)_{ij}\right)^{2}\) the miss in one cell, squared.\(V \log(V/WH)\) the ratio miss, 0 when rebuilt equals real; a cell with \(V = 0\) adds nothing here, since \(0 \log 0\) counts as 0. \(\log\) is the natural log, so the cost is in nats, the unit of the natural log, as bits are the unit of log base 2.\(\operatorname{SE}\) the squared error.\(\operatorname{KL}\), in full \(\operatorname{KL}(V \,\Vert\, WH)\), read aloud as the KL divergence of \(V\) from the rebuild \(W H\).\(-V + WH\) keeps the cost at 0 for a perfect fit and above 0 otherwise, even when the totals of \(V\) and \(W H\) differ. This is the generalized KL divergence. The KL Divergence page compares lists of chances that each sum to 1, and here the totals need not match.Each cost is 0 only when \(V = W H\), so lowering either drives the rebuild toward the data.

Section 4 lowers these costs while keeping every entry non-negative.

4 Multiplicative updates

Builds on the learning rate (Gradient Descent, section 1.2)

Each update multiplies every entry by a ratio, what the data asks for over what the model already gives. Below, \(W^{T}\) is \(W\) turned on its side, its transpose.

Deriving the gradient from the squared error of Section 3 shows why a step size chosen per entry turns a gradient step into a multiplication.

Nudging one activation changes its frame's rebuild by that template, so its gradient adds up the frame's misses weighted by the template. Taking a step against it, with a step size chosen per entry, gives a ratio.
\(\displaystyle \frac{\partial \operatorname{SE}}{\partial H} = {2 W^{T}(WH - V)}\)
Here a miss is rebuild minus data, the opposite sign from the miss of Section 3. Each entry adds up its frame's misses, weighted by its template, so an activation whose template is rebuilt too loud gets a positive gradient and is pushed down.
\(\displaystyle G = {W^{T}WH - W^{T}V}\)
Opening the bracket and halving gives \(G\), the model side minus the data side.
\(\displaystyle H \leftarrow {H - \eta \odot G}\)
A gradient descent step on half the gradient, with its own learning rate for every entry of \(H\).
\(\displaystyle \eta = \frac{H}{W^{T}WH}\)
With this choice the model side cancels, and what is left is \(H\) times data side over model side, the first line of the card in Figure 4.
\(\partial \operatorname{SE}/\partial H\) the gradient, how fast \(\operatorname{SE}\) changes as each entry of \(H\) is nudged.\(W^{T}(WH - V)\) each cell's miss passed back through the templates; the 2 comes from the square.\(G\) half the gradient.\(\eta\) the learning rate, here a separate one for each entry of \(H\).\(\odot\) entry-by-entry product.

Figure 4. Steps 0 to 3 are one fit; step 4 is a separate stuck run.

Each entry is multiplied by a ratio, what the data pulls toward over what the current model already gives. If the rebuild is too small, the ratio is above 1 and the entry grows; if it is too big, the ratio is below 1 and the entry shrinks; at a perfect fit the ratio is 1 and the entry stays. Positive times positive stays positive, so no clipping is needed.
\(\displaystyle \htmlClass{eqt}{\htmlData{k=H}{H}} \leftarrow H \odot \frac{W^{T}V}{W^{T}WH}\)
Each activation grows where its template matches the data better than it matches the rebuild, and shrinks where it matches the rebuild better.
\(\displaystyle \htmlClass{eqt}{\htmlData{k=W}{W}} \leftarrow W \odot \frac{VH^{T}}{WHH^{T}}\)
The same comparison from the activations' side updates the templates. Alternating the two lines drives the error toward 0 on the two-note example (step 3).
\(W^{T} V\) how strongly each template matches each frame of the data.\(W^{T} W H\) the same match measured on the current rebuild.\(\odot\) and the fraction bar work entry by entry.\(V H^{T}\) and \(W H H^{T}\) the data and the rebuild, matched against each activation row.
The same ratio idea for the KL cost of Section 3, the form the thesis uses (eq 4.26).
\(\displaystyle H \leftarrow H \odot \frac{W^{T} \frac{V}{WH}}{W^{T} 1}\)
Each cell's ratio of data to rebuild is passed back through the templates and divided by how much each template is used.
\(\displaystyle W \leftarrow W \odot \frac{\frac{V}{WH} H^{T}}{1 H^{T}}\)
The same from the activations' side, divided by how much each activation row is used.
\(V/WH\) the cell-by-cell ratio of data to rebuild, 1 wherever the fit is perfect.\(1\) a matrix of ones the size of \(V\), so \(W^{T} 1\) and \(1 H^{T}\) add up how much each template and each activation is used.

Each KL line is also a gradient step with a step size per entry, chosen as in the gradient card so that the step becomes a ratio. The authors prove the cost never goes up and state that it stops changing at a stationary point, where the gradient is zero so the update no longer moves (the same authors, 2001, Theorems 1 and 2). An entry stuck at 0 also stops changing, and a global minimum is not guaranteed, as the separate run in step 4 of Figure 4 shows. Alternating the two lines of either card is the whole algorithm.

Section 5 chooses how many templates to fit.

5 Choosing the rank

Too few templates blur sounds together; too many split one sound or copy noise. On the two-note example one template cannot hold both notes, while two or more rebuild it exactly. In its two-burst example the thesis assumes the number of sources is known, and points to a way to estimate it (p. 45).

Take an illustrative recording with three sounds, a steady hum that stops partway, speech-band bursts like syllables, and a keyboard click every 12 frames. A fit starts from random positive templates and activations, scaled to the data's loudness and fixed so every visit shows the same fit. One round is steps 1 and 2 of Figure 4, the \(H\) line and then the \(W\) line, and no round can raise the error.

Rank

squared error about 0

Figure 5. 1 Rounds find sounds; 2 too few share, too many split.

At rank 3 each sound gets its own template; the click template dips at the speech bins and the speech template fills that dip back in. At rank 2 the hum and the click share one template, so the clicks come back faint; at rank 4 the hum splits across two blue templates and the error does not drop further. Rank 1 settles within a few rounds at a high error, since one template can only average the three sounds.

6 NMF in code

Builds on STFT windows (The STFT and Spectrograms, section 4)

x is any mono recording. This is the unsupervised version, one fit on one recording with no templates learned beforehand. Passing V with frequency bins as rows makes scikit-learn's W the templates and H the activations, the names on this page; scikit-learn's own docs warn that the literature often swaps them.

import numpy as np
import scipy.signal as ss
import sklearn.decomposition as sd

_, _, Z = ss.stft(x, nperseg=512)
V = np.abs(Z)

nmf = sd.NMF(3, solver="mu")
nmf.set_params(beta_loss=1)
W = nmf.fit_transform(V)
H = nmf.components_
  1. 1The complex STFT Z and its magnitude V, the matrix of Section 1.
  2. 2Rank 3 with multiplicative updates; beta_loss=1 is the KL cost of Section 3 and needs solver="mu". The default start here is "nndsvda", built from the SVD with its zero entries filled by the data average, so it is the same on every run.
  3. 3Fits the model of Section 1; W has one row per frequency bin and 3 columns, and H is 3 by the number of frames.

The next block runs the squared-error updates of Section 4 on the two-note spectrogram of Figure 1.

import numpy as np
Wt = np.c_[[2,1,0,0], [0,0,1,2]]
V = Wt @ [[1, 0, 1], [0, 1, 1]]
rng = np.random.default_rng(0)
W = rng.random((4, 2)) + 0.1
H = rng.random((2, 3)) + 0.1
e = 1e-9
for _ in range(200):
    H *= W.T@V / (W.T@W@H + e)
    W *= V@H.T / (W@H@H.T + e)
  1. 1Builds V from the two notes and their activations, as in Figure 1.
  2. 2A random positive start; + 0.1 keeps every entry above 0, since a 0 never changes under multiplication (Section 8).
  3. 3The guard e, which avoids dividing by 0, the loop and the activation update.
  4. 4The template update.

It returns the two notes up to scale, so each template can come back multiplied by some number, with its activation row divided by the same number.

7 NMF for audio

Separation with fixed templates comes first, then the way back to sound with the mixture phase, templates that last several frames, and the thesis's room matching.

7.1 Separating sounds with learned templates

Learn speech templates from clean speech and noise templates from noise alone. On a noisy recording, keep both sets fixed and fit only the activations; the speech templates times their activations rebuild the speech (the thesis, section 4.7.1, eqs 4.27 to 4.29).

7.2 Reusing the mixture phase

Builds on magnitude and phase (Fourier Transform and the FFT, section 4) and the Wiener gain (The Wiener Filter, section 1)

Each STFT cell is a complex number. Its size is the loudness kept in \(V\), its angle says where the wave is in its cycle, and NMF throws the angle away. Take one noisy cell that NMF rebuilds as a speech part plus a noise part.

The two parts rebuild the cell's size only roughly. Using the speech magnitude directly would ignore that miss; dividing by the rebuild and scaling the real cell corrects the size and borrows the angle (the thesis notes this compensates for “misestimation in the magnitude spectrogram”, p. 49).

Keep the speech share of every cell, take the angle from the recording itself, and go back to a waveform (thesis eqs 4.29 and 4.34). The shares come from the model of Section 1, split into speech and noise templates.
\(\displaystyle \hat{S} = \frac{W_{s} H_{s}}{W H} \odot Y\)
The mask is the speech share of the rebuild, between 0 and 1, so in Figure 7 the cleaned cell is a shorter copy of the noisy cell at the same angle.
\(\displaystyle \hat{s} = {\text{inverse STFT of } \hat{S}}\)
Every cleaned cell, size from the share and angle from the mix, goes back to a waveform.
\(W_{s} H_{s}\) the rebuild from the speech templates only (eq 4.29).\(WH\) the rebuild from all templates, speech and noise, with \(H\) fitted by the KL \(H\) line of Section 4 while both sets of templates stay fixed (eq 4.28).Their ratio a mask between 0 and 1 per cell, the same idea as the Wiener gain.\(Y\) the complex STFT of the recording; multiplying by it reuses the mixture phase, as spectral subtraction does (eq 4.34).\(\hat{s}\) the separated waveform, rebuilt by overlap-add.

Continuing the first block of Section 6, the next block keeps template k's share of every cell, puts it on the complex Z and inverts. Section 7.1's supervised version fixes \(W\) before fitting; this one just picks a template.

k = 0
Vk = np.outer(W[:, k], H[k])
mask = Vk / (W @ H + 1e-9)
Sk = mask * Z
_, xk = ss.istft(Sk, nperseg=512)
  1. 1Rebuilds template k's part and divides by the full rebuild, the mask of the first card line.
  2. 2Applies the mask to the complex Z, so the mixture phase is kept, and inverts, the second card line.

Plain NMF treats every frame alone. Sounds and rooms have time patterns, so Section 7.3 lets templates last several frames.

7.3 Convolutive NMF

Builds on convolution as a sliding sum (LTI Systems and Convolution, section 5)

A sound is a short movie, not one spectrum. In convolutive NMF (Smaragdis 2004) each template lasts a few frames and slides along time, the same sliding weighted sum as an FIR filter.

Plain NMF would need two separate templates, one per frame, and would lose the fact that one always follows the other.

A template becomes a short movie that slides along time, each of its frames played one step later than the one before.
\(\displaystyle V \approx {\sum_{t=0}^{T-1} W(t)\, \operatorname{shift}_{t}(H)}\)
In Figure 8 \(T = 2\). \(W(0)\) times \(H\) plays the template's first frame at each spike; \(W(1)\) times \(H\) shifted one frame plays its second frame one frame later, and the two add up to \(V\).
\(\Sigma\) over \(t\) adds the \(T\) shifted copies, one per template frame.\(W(t)\) frame \(t\) of every template, with \(T\) the template length in frames; \(T = 1\) gives back plain NMF (Smaragdis 2004, eq 4; thesis eq 5.26, p. 69).\(\operatorname{shift}_{t}(H)\) \(H\) moved \(t\) frames to the right with zeros filled in on the left, so each spike plays the whole template.

Learned from clean speech, such templates also serve the supervised separation of Section 7.1 (Smaragdis 2007).

7.4 Dereverberation and room matching

The thesis's goal is example-based editing, making a recording sound drier or making it sound like the room of an example recording. A room smears each sound with a decaying tail of echoes, the dry sound convolved with the room's response. In the thesis model speech is still built from the same dry templates, and each template's activation row is convolved with its own decaying tail.

The convolutive card of Section 7.3 put a time pattern inside the templates; here the room's tail sits on the activations instead. Pulling that tail out gives a knob for how much room you hear, or lets you swap in the tail of an example recording's room.
\(\displaystyle Y \approx W_{d} (H_{d} \ast R)\)
In Figure 9 each spike of the dry row is smeared into a scaled copy of the tail \(R\), and the dry template \(W_{d}\) plays that smeared row.
\(\displaystyle R(t) = e^{\lambda t}\)
Figure 9's tail halves each frame, an illustrative decay; the fit starts each kernel as this curve instead (eq 5.33, p. 72). The more negative \(\lambda\) is, the faster the tail dies away.
\(\displaystyle R_{\text{new}} = R^{\beta}\)
With \(R\) scaled to peak 1, the power keeps the peak and changes only how fast the tail falls.
\(Y\) the reverberant spectrogram; \(W_{d}\) the dry speech templates, learned once from clean speech.\(H_{d} \ast R\) each dry activation row convolved (\(\ast\)) with its own decaying kernel (thesis eq 5.29, p. 71); with no kernel it is the model of Section 1.\(t\) the frame within the kernel, counted from 1; \(\lambda\) a negative decay factor set per frequency band, \(\text{between } -1.5 \text{ and } -0.9\) in the thesis.At each iteration the thesis raises the kernel entries to a power \(\text{between } 0.8 \text{ and } 0.9\), which it describes as enforcing sparsity on the kernel (eq 5.34). The dry templates were learned with the activations raised to a power \(\text{between } 0.9 \text{ and } 0.98\) each iteration, which it describes as sparsifying them (eq 5.31).\(\beta\) above 1 shortens the tail and below 1 lengthens it. For room matching the thesis fits \(\beta\) per component so that \(R^{\beta}\) matches the example recording's kernel under KL, with \(\beta \text{ between } 0.5 \text{ and } 2\) (eqs 5.36 and 5.37, p. 74).The reverberant recording's phase is reused (eq 5.39), so some old reverb can survive (Section 8).

The thesis learned the speech templates once offline (25 templates, 500 iterations), then decomposed each 10-second recording (section 5.13). Plain NMF and its mask undo a blend of parts in one recording, and convolutive NMF extends that to blends over time, the counterpart of the blend across sensors that Independent Component Analysis undoes.

Common NMF failures, what they look like and the fix.

Feed NMF a magnitude STFT, as the thesis does, not power; power squares every cell, so the loudest bins would rule the fit even more. Scale the templates to peak 1 before comparing runs, since a template and its activation row can trade any scale. The cost should fall fast and then flatten; a curve still falling at max_iter needs more iterations, and a curve flat at a high value points to a bad start or too low a rank.
