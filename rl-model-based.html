A model-based agent learns, or is given, a model of the world. It plans or practices inside that model, and acts in the real world to collect steps that improve the model, the policy or both (Figure 1). The methods in Value-Based RL and Policy-Based and Actor-Critic Methods: REINFORCE, PPO and SAC learn from real steps only; they are model-free.

1 Dyna

A chess player tries moves in their head before touching a piece; a model lets an agent do the same before spending real steps.

A model predicts the next state and reward from a state and a move; planning uses it to look ahead or practice without the real world. Dyna (Sutton 1991) runs the Q-learning update from Value-Based RL on imagined steps as well as real ones:

Q-learning moves the score of the move played a little toward a target built from that step.
target = r + γ · max Q(s′, a′)
Q(s, a), the Q-value, is the future reward expected from move a in state s. The target is the reward r the move earned plus the highest score in the state s′ it led to, max Q(s′, a′) over every move a′ there. The discount γ, from 0 to 1, shrinks that future score for the delay.
Q(s, a) ← Q(s, a)
+ α · (target − Q(s, a))
The score of move a in state s moves a fraction α, the learning rate, of the way toward the target (the arrow means replace with).

Dyna-Q adds n imagined steps from a remembered model after each real one (Sutton and Barto’s RL textbook, 2018, section 8.2). The code runs one Dyna-Q step on the book’s 6 by 9 maze. env_step(s, a) is the maze’s rule, returning (r, s_next).

import random
import numpy as np

alpha, gamma, eps, n = 0.1, 0.95, 0.1, 5   # book's maze
Q = np.zeros((54, 4))   # 6 x 9 squares, 4 moves
model = {}              # (s, a) -> (r, s_next)
GOAL = 8                # top-right square, episode ends

def q_update(s, a, r, s_next):
    future = 0.0 if s_next == GOAL else Q[s_next].max()
    Q[s, a] += alpha * (r + gamma * future - Q[s, a])

def dyna_step(env_step, s):
    if random.random() < eps:
        a = random.randrange(4)
    else:
        a = int(random.choice(np.flatnonzero(Q[s] == Q[s].max())))
    r, s_next = env_step(s, a)
    q_update(s, a, r, s_next)
    model[(s, a)] = (r, s_next)
    for _ in range(n):
        (s_m, a_m), (r_m, s_m_next) = random.choice(list(model.items()))
        q_update(s_m, a_m, r_m, s_m_next)
    return s_next
  1. 1Sets the book’s maze values, the Q-table, an empty model and the goal square.
  2. 2The Q-learning update, line 2 of the Q-learning card above, with no future past the goal.
  3. 3Picks a move ε-greedily, the best-scoring move (ties at random) except for a small chance ε of a random one, and takes one real step.
  4. 4Learns from the real step and stores it in the model.
  5. 5Replays n imagined steps, each a stored step picked at random (the book picks a seen state, then a move tried there); n is the count that varies in Figure 2.

Each imagined update can carry value one square further back from the goal, so the reward found there spreads through the maze without new real steps (the RL textbook, Example 8.1).

2 AlphaZero and MuZero

AlphaZero (Silver et al. 2018) uses a game’s rules for a tree search, a look-ahead over move sequences that a network steers, and learns from games against itself. MuZero (Schrittwieser et al. 2020) learns the model instead:

One network steers the search and learns to predict what the search finds; MuZero also learns the model it searches with.
(p, v) = f(s)
In AlphaZero, from a position s, one network f gives p, a probability for each move, and v, the predicted result. The rules produce each next position. The search tries moves with high p, few visits and a high average v so far, and scores each position where a line stops with v instead of playing the game to the end.
π(a) ∝ N(a)
N(a) counts how often the search tried move a from the current position, and π is those counts scaled to probabilities (∝ reads "in proportion to"). The move played is drawn from π or is its most visited move.
loss = (z − v)2 − π · log p
z is the game’s final result, −1 for a loss, 0 for a draw, +1 for a win. The first term pulls v toward it; the second pulls p toward the search’s π, so the next search starts from better guesses (the paper adds weight decay).
h0 = repr(observation)
MuZero first uses a representation network, repr, to turn what the agent sees into h0, a hidden state (a vector of numbers).
(r, hk+1) = dynamics(hk, a)
The dynamics network stands in for the rules: from hidden state hk and move a, it predicts the reward and the next hidden state.
(p, v) = f(hk)
The same move probabilities and value as AlphaZero, read from the hidden state. The hidden state only has to predict rewards, moves and values, never to redraw the screen.
loss = Σk [ℓ(uk, rk)
+ ℓ(zk, vk) + ℓ(πk, pk)]
MuZero replays a stored game and unrolls the dynamics 5 moves along the moves really played. ℓ is an error between a target and a prediction, and the sum over the unrolled steps k trains all three networks together: each predicted reward toward the reward u really seen, each value toward the observed return, and each p toward the search’s π at that step.

3 World Models and Dreamer

World Models (Ha and Schmidhuber 2018) train a small controller inside a learned model of the game, then run it for real. Making the model’s predictions more random kept the controller from exploiting the model’s errors. An agent that counts only the reward inside a fixed window of imagined steps turns shortsighted. Dreamer (Hafner et al. 2020) learns a compact hidden-state model from replayed experience and trains its actor and critic on imagined runs inside it; the critic estimates the reward past the window, so the actor still aims for rewards that come later.

Dreamer scores an imagined run by the rewards inside the window plus the critic’s value at its end.
return = r0 + γ r1
+ … + γH−1 rH−1 + γH v(sH)
The model imagines H steps ahead and predicts a reward r at each; the discount γ shrinks later ones. The critic’s value v(sH) at the last imagined state stands in for every reward past the window, so a short window still counts the long run. The actor is trained to raise this return, and Dreamer averages such estimates over window lengths up to H (its Vλ target).
