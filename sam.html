1 What SAM fixes

Gradient descent looks only at the loss where the weights are, so it settles in whichever basin it rolls into, narrow or wide. Two minima with the same training loss can generalize very differently: in a narrow, sharp minimum a slight shift between training and test data raises the loss a lot; in a wide, flat one it barely matters (Keskar and others 2017 tied the sharp minima of large-batch training to worse test accuracy). Sharpness-Aware Minimization (SAM), from Foret and others (2021), changes what training minimizes so that flat minima win.

SAM improved image classifiers on CIFAR and ImageNet and made them more robust to noisy labels. Its biggest effect was on models with weak built-in assumptions: Chen, Hsieh and Gong (2022) found that vision transformers and MLP-Mixers trained from scratch on ImageNet with SAM beat ResNets of similar size without large-scale pretraining or strong augmentation, and that SAM made their loss landscapes much smoother.

2 Score each point by its worst neighbour

On this page \(\epsilon\) is SAM’s perturbation, a small move of the weights; it is unrelated to Adam’s \(\epsilon\), the tiny constant that keeps a divide away from zero.

SAM’s objective: the worst loss a small step away
\({\displaystyle \begin{aligned} &\min_{\htmlStyle{color:#2c3e50}{w}}\; L^{\text{SAM}}(\htmlStyle{color:#2c3e50}{w}) \\ L^{\text{SAM}}(\htmlStyle{color:#2c3e50}{w}) &= \max_{\lVert\epsilon\rVert \le \htmlStyle{color:#a04000}{\rho}} L(\htmlStyle{color:#2c3e50}{w} + \epsilon) \end{aligned}}\)
Instead of the loss at the weights \(w\), SAM minimizes the largest loss found anywhere within a distance \(\rho\) (rho) of them. \(\epsilon\) here is a small move of the weights, and \(\lVert\epsilon\rVert\) its length (Vectors and Matrices). A point at the bottom of a narrow basin scores badly, because a small move climbs a steep wall; a point in a wide basin scores well, because every small move stays low.
\({\displaystyle \begin{aligned} L^{\text{SAM}}(\htmlStyle{color:#2c3e50}{w}) &= L(\htmlStyle{color:#2c3e50}{w}) \\ &\quad + \text{sharp}(\htmlStyle{color:#2c3e50}{w}) \\ \text{sharp}(\htmlStyle{color:#2c3e50}{w}) &= \max_{\lVert\epsilon\rVert \le \htmlStyle{color:#a04000}{\rho}} L(\htmlStyle{color:#2c3e50}{w}+\epsilon) \\ &\quad - L(\htmlStyle{color:#2c3e50}{w}) \end{aligned}}\)
The same score split in two: the ordinary loss, plus the sharpness, how much the loss can rise within \(\rho\) of the weights. Minimizing both asks for weights that fit the data and sit where the loss is flat. Flat regions tend to generalize better, because test data shifts the loss surface slightly and a flat minimum stays low under the shift (Understanding Model Errors).

3 Finding the worst neighbour with one gradient

The objective needs the worst point within \(\rho\). SAM estimates it from the gradient it already has.

One gradient instead of a search
\({\displaystyle \htmlStyle{color:#1f618d}{\hat\epsilon}(\htmlStyle{color:#2c3e50}{w}) = \htmlStyle{color:#a04000}{\rho}\,\frac{\htmlStyle{color:#c0392b}{\nabla L(w)}}{\lVert \htmlStyle{color:#c0392b}{\nabla L(w)}\rVert}}\)
Searching every move within \(\rho\) is too expensive, so SAM takes one guess: the steepest uphill direction, which is the gradient. It scales the gradient to length \(\rho\); the hat marks this one-step estimate of the worst move.
\({\displaystyle \htmlStyle{color:#c0392b}{g_{\text{SAM}}} = \nabla L(w)\,\Big|_{\,\htmlStyle{color:#2c3e50}{w} + \htmlStyle{color:#1f618d}{\hat\epsilon}}}\)
Then it reads the gradient again at the moved point \(w+\hat\epsilon\). This second gradient points downhill from the worst nearby spot, so it carries the information about the walls around \(w\).
\({\displaystyle \htmlStyle{color:#2c3e50}{w} \leftarrow \htmlStyle{color:#2c3e50}{w} - \htmlStyle{color:#7d3c98}{\alpha}\,\htmlStyle{color:#c0392b}{g_{\text{SAM}}}}\)
Finally SAM goes back to \(w\) and lets the base optimizer, SGD or Adam, step with that second gradient. Each SAM step therefore costs two forward and backward passes.

6 SAM in PyTorch: perturb, then step

In code, perturb is the first pass; closure returns the minibatch loss. SAM’s official code is in JAX, Google’s array library (google-research/sam); this is the same algorithm in PyTorch.

import torch
from torch import stack
def perturb(ps, closure, rho):
    closure().backward()
    gs = [p.grad for p in ps]
    ns = [g.norm() for g in gs]
    k = rho / stack(ns).norm()
    ds = [k * g for g in gs]
    with torch.no_grad():
        for p, d in zip(ps, ds):
            p.add_(d)  # θ + ε̂
    return ds
  1. 1Reads the gradient at \(\theta\).
  2. 2Scales it to length \(\rho\), which is \(\hat\epsilon\), the first line of the card.
  3. 3Moves every weight to \(\theta+\hat\epsilon\) and returns \(\hat\epsilon\).
ds = perturb(ps, closure, rho)
opt.zero_grad()
closure().backward()  # θ + ε̂
with torch.no_grad():
    for p, d in zip(ps, ds):
        p.sub_(d)  # back to θ
opt.step()  # steps with g_SAM
  1. 1Moves to \(\theta+\hat\epsilon\) with perturb.
  2. 2Reads the gradient there, \(g_{\text{SAM}}\), the second line.
  3. 3Moves the weights back to \(\theta\).
  4. 4Lets the base optimizer step with \(g_{\text{SAM}}\).

7 When to use it

SAM pays off when generalization, not training loss, is the bottleneck: image classifiers trained from scratch, vision transformers and MLP-Mixers without large-scale pretraining, and training on noisy labels. It doubles the cost of every step, so it fits best when compute allows it and the base optimizer already trains well. For large language models trained on huge datasets, where the model rarely overfits, it is not part of the usual recipe.

8 When it runs and what it carries

SAM wraps the base optimizer and runs on every training step: two forward and backward passes, then one base-optimizer step. Between the passes it holds the move \(\hat\epsilon\), one extra copy of the weights’ size, on top of the base optimizer’s own state (for example Adam’s two averages). Nothing of SAM’s own carries over between steps, so a checkpoint only needs the base optimizer’s state.

9 Failure modes and tips

SAM’s trouble comes from its second pass and its radius.
symptomcausefix
training takes about twice as longevery step runs two forward and backward passesbudget for it, or apply SAM only on some steps
