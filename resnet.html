1 Big picture: the degradation problem

He et al. trained plain 20- and 56-layer networks on CIFAR-10, and plain 18- and 34-layer networks on ImageNet [1]. In both, the deeper plain net had the higher training error, so it was not overfitting. Nor was it vanishing gradients: the plain nets used batch normalization, and the authors checked that forward signals and backward gradients kept healthy sizes. Deeper plain nets are simply harder to optimize.

The paper's thought experiment: a deeper net could copy a shallower one and make its extra layers the identity, so it should never be worse. The solver fails to find that solution. ResNet makes it easy. Every forward pass adds a shortcut around each block; nothing carries over between batches. ResNet is the default backbone for image classification and detection, the DDPM U-Net is built from residual blocks, and residual connections are also what lets transformers stack many blocks.

Every convolution in ResNet, and in the plain networks it was compared with, is followed by batch normalization, which normalizes each channel over the batch and uses stored averages at test time. With one or two images per GPU, detection models swap it for GroupNorm [2, 6].

2 Residual learning

What a residual block learns, built up in order.
\(\displaystyle {\mathcal{H}(\htmlClass{eqt sym-skip}{\htmlStyle{color:var(--sym-skip)}{x}})}\)
The mapping the block should learn from its input \(x\).
\(\displaystyle {\htmlClass{eqt sym-res}{\htmlStyle{color:var(--sym-res)}{\mathcal{F}(x)}} = \mathcal{H}(\htmlClass{eqt sym-skip}{\htmlStyle{color:var(--sym-skip)}{x}}) - \htmlClass{eqt sym-skip}{\htmlStyle{color:var(--sym-skip)}{x}}}\)
The residual: only the change the block makes to its input.
\(\displaystyle {y = \htmlClass{eqt sym-res}{\htmlStyle{color:var(--sym-res)}{\mathcal{F}(x, \{W_i\})}} + \htmlClass{eqt sym-skip}{\htmlStyle{color:var(--sym-skip)}{x}}}\)
The block's output: the change computed by its layers with weights \(W_i\), plus the input carried unchanged on the shortcut.
\(\displaystyle {y = \htmlClass{eqt sym-res}{\htmlStyle{color:var(--sym-res)}{\mathcal{F}(x, \{W_i\})}} + W_s\,\htmlClass{eqt sym-skip}{\htmlStyle{color:var(--sym-skip)}{x}}}\)
When the channels or the size change, a 1×1 projection \(W_s\) on the shortcut makes \(x\) fit.
If the best a block can do is nothing, it only has to push \(\mathcal{F}\) to zero, which is easier than learning the identity through stacked nonlinear layers.

An identity shortcut adds no weights and no compute beyond one addition per value.

5 Evidence

DepthPlainResNet

Top-1 error on ImageNet validation, 10 crops per image (the ResNet paper, Table 2).

With plain layers the 34-layer net is worse than the 18-layer one; with shortcuts it is better. At ILSVRC 2015 an ensemble of six ResNets of different depth reached 3.57% top-5 test error and took first place. On CIFAR-10 a 110-layer ResNet reached 6.43% error; a 1,202-layer one still trains but does worse, 7.93%, which the authors attribute to overfitting [1].

6 Shortcut options

When a stage doubles the channels, the shortcut must change shape too. The paper compared three options on ResNet-34: (A) pad the extra channels with zeros, adding no weights; (B) use a projection only where dimensions grow; (C) use projections on every shortcut.

OptionShortcutsTop-1 error
Aidentity, zero-padding where channels grow25.03%
Bprojection where dimensions grow, identity elsewhere24.52%
Cprojection everywhere24.19%

ResNet-34, 10-crop top-1 error on ImageNet validation (the ResNet paper, Table 3).

Projections help a little, so the paper concludes they are "not essential for addressing the degradation problem" [1]. Identity shortcuts matter most in the bottleneck block, where a projection on every shortcut would double the block's cost.

7 The bottleneck block

ResNet-50 and deeper use a bottleneck block: a 1×1 layer shrinks the channels, a 3×3 works on the narrow map, and a 1×1 widens it back, the same reduce trick as Inception's 1×1 layers.

ResNet-50 needs 3.8 billion FLOPs per image and ResNet-152 11.3 billion, both less than VGG-16's 15.3 billion [1].

9 In practice

torchvision.models.resnet50(weights=...) loads a pretrained model. torchvision puts a bottleneck's stride on the 3×3 instead of the first 1×1, the variant often called ResNet v1.5 [4]; zero_init_residual=True zeroes the last batch-norm \(\gamma\) in each block, so every block starts as the identity like the toy's residual version; it is off by default. The paper trained with SGD, momentum 0.9, weight decay 0.0001, BatchNorm after every convolution and no dropout [1].

A complete bottleneck as torchvision builds it. Conv is Conv2d with bias=False, since batch norm follows every convolution; self.f is \(\mathcal{F}(x)\) with \(i\) channels in and middle width \(m\); the 3×3 carries the stride \(s\), and the output is \(4m\) wide.

import torch
import torch.nn as nn
from torch.nn import Conv2d
from functools import partial

Conv = partial(Conv2d, bias=False)

def conv_bn(i, o, k, s=1):
    c = Conv(i, o, k, s, k // 2)
    bn = nn.BatchNorm2d(o)
    return nn.Sequential(c, bn)

class Bottleneck(nn.Module):
    def __init__(self, i, m, s=1):
        super().__init__()
        o = 4 * m
        self.f = nn.Sequential(
            conv_bn(i, m, 1),
            nn.ReLU(),
            conv_bn(m, m, 3, s),
            nn.ReLU(),
            conv_bn(m, o, 1))
        # default: 1×1 projection
        skip = conv_bn(i, o, 1, s)
        if s == 1 and i == o:
            skip = nn.Identity()
        self.skip = skip

    def forward(self, x):
        h = self.f(x)  # F(x)
        y = h + self.skip(x)
        return torch.relu(y)

block = Bottleneck(64, 64)
x = torch.randn(1, 64, 56, 56)
y = block(x)  # (1, 256, 56, 56)
  1. 1A convolution with no bias followed by batch norm, used for every layer.
  2. 2\(\mathcal{F}(x)\), the bars of Figure 4: 1×1 narrow, 3×3 with the stride, 1×1 back to \(4m\).
  3. 3The shortcut: the identity when shapes match, otherwise a 1×1 projection.
  4. 4Adds the shortcut, line 3 of the card in Section 2, then ReLU.
  5. 5The first block of stage 1: 64 channels in, 256 out.
