DINO: Self-Distillation with No Labels

A student learns from a teacher built from itself, whose outputs are centered and sharpened so no single output wins for every image.

1 The collapse problem, in one page

With no negatives to push against, one output for every image matches every pair and says nothing: that is collapse. In a subtler dimensional collapse, the embeddings spread along only a few directions of the space and stay flat along the rest; Failure Modes and Checks plots it.

The full collapse story is on BYOL: Bootstrap Your Own Latent, which also states the pattern all three methods share: every target side sits behind a stop-gradient.

2 DINO matches a student to a centered, sharpened teacher

DINO (self-distillation with no labels, Caron et al. 2021; the student learns from a teacher built from itself) trains a student network to copy a teacher, a momentum encoder of the student (MoCo’s momentum rule). Two edits to the teacher’s output, centering and sharpening, stop collapse. Each network has \(K\) outputs, 65,536 in DINO. A softmax turns them into shares that sum to 1, and dividing by a temperature first sets how peaked the shares are, as in Knowledge Distillation but set low for the teacher. The student matches the teacher’s shares by cross entropy, which penalises the student when its shares differ from the teacher’s.

The student and the teacher see the two views

The student reads one view and the teacher reads the other. The teacher is a slow copy of the student.

Center the teacher

Subtract the center, the running average of the teacher’s outputs. What every image shares is taken out, so no single output can win for every image.

Sharpen with the low temperature

Divide by the small teacher temperature. The remaining gaps stretch out, so each image’s top output stands out.

The student matches the shares

The student copies the teacher’s shares. Then the teacher follows the student by EMA and the center moves toward the batch mean.

The teacher turns an image into target shares that the student learns to match; it subtracts a running center, then sharpens with a low temperature.
\(\displaystyle \htmlClass{eqt}{\htmlData{k=Pt}{\htmlStyle{color:#7d6608}{P_{t}}}}(x) = \operatorname{softmax}(\frac{\htmlStyle{color:#1f618d}{g_{t}}(x) - \htmlClass{eqt}{\htmlData{k=c}{\htmlStyle{color:#117a65}{c}}}}{\htmlClass{eqt}{\htmlData{k=tau_t}{\htmlStyle{color:var(--sym-temp)}{\tau _{t}}}}})\)
The teacher’s targets are its outputs, centered and then sharpened. For one image \(x\), \(g_{t}(x)\) is the teacher’s \(K\) raw outputs. The center \(c\) is a running average of the teacher’s outputs over recent batches. \(\tau _{t}\) is the teacher’s small temperature. \(P_{t}\) is the softmax of the result, the teacher’s shares. Subtracting \(c\) (centering) removes what every image has in common, so no single output can win for every image; on its own it pushes the shares toward flat. Dividing by the small \(\tau _{t}\) (sharpening) stretches the remaining gaps, so each image’s top output stands out; on its own it lets one output win everywhere. Together they leave each image its own peak, which the student copies. The student uses its own, higher temperature and no centering.

3 One DINO training step, in code

A DINO step trains the student, then moves the teacher toward it by EMA and the center \(c\) toward the batch mean.

def run(TAU_STUDENT, TAU_TEACHER, OUT_DIM, LAM_START, CENTER_MOMENTUM, TOTAL_STEPS, INPUT_DIM, LR, BATCH, IMG):  # pass your own sizes and settings
    import copy, math
    import torch
    import torch.nn as nn
    import torch.nn.functional as F

    def dino_loss(s_out, t_out, c, tau_s=TAU_STUDENT, tau_t=TAU_TEACHER):
        P_t = F.softmax((t_out - c) / tau_t, dim=-1)     # center, sharpen
        log_P_s = F.log_softmax(s_out / tau_s, dim=-1)
        return -(P_t * log_P_s).sum(dim=-1).mean()

    K_OUT, LAM_BASE, M_C = OUT_DIM, LAM_START, CENTER_MOMENTUM   # DINO uses 65,536 outputs
    WD_START, WD_END = 0.04, 0.4
    k, K_STEPS = 0, TOTAL_STEPS                 # step k
    lam = 1 - (1 - LAM_BASE) * (math.cos(math.pi * k / K_STEPS) + 1) / 2
    wd = WD_END - (WD_END - WD_START) * (math.cos(math.pi * k / K_STEPS) + 1) / 2
    student = nn.Sequential(nn.Flatten(), nn.Linear(INPUT_DIM, K_OUT))
    teacher = copy.deepcopy(student).requires_grad_(False)
    c = torch.zeros(K_OUT)
    opt = torch.optim.AdamW(student.parameters(), lr=LR, weight_decay=wd)

    x1, x2 = torch.rand(BATCH, 3, IMG, IMG), torch.rand(BATCH, 3, IMG, IMG)
    s1, s2 = student(x1), student(x2)
    with torch.no_grad():
        t1, t2 = teacher(x1), teacher(x2)
    L = (dino_loss(s1, t2, c) + dino_loss(s2, t1, c)) / 2
    opt.zero_grad()
    L.backward()
    opt.step()
    with torch.no_grad():
        for p_t, p_s in zip(teacher.parameters(), student.parameters()):
            p_t.mul_(lam).add_(p_s, alpha=1 - lam)
        c = M_C * c + (1 - M_C) * torch.cat([t1, t2]).mean(dim=0)

4 When to use DINO

Use DINO to pretrain a vision transformer when labels are scarce, and for any job that reuses the learned features without a trained head.

The learned ViT features carry explicit semantic segmentation information, so they suit segmentation-style reuse. The features are also excellent k-NN classifiers, so plain nearest-neighbor voting over the frozen features is a real use, not a toy check.

DINO runs every training step. It carries a teacher network and a center alongside the student, and updates the teacher by EMA and the center toward the batch mean after each step.

5 Failure modes and tips

Center rate too high. Cause: the center rate is 0.999, so the center lags too far behind the teacher. Symptom: k-NN collapses to chance. Fix: keep the center rate at 0.9.

No centering or no sharpening. Cause: one of the two teacher edits is dropped. Symptom: collapse. Fix: keep both edits on.

Teacher temperature too high, no warm-up. Cause: \(\tau _{t}\) goes above 0.06 without warm-up. Symptom: collapse. Fix: warm \(\tau _{t}\) up from 0.04 to 0.07 over the first 30 epochs.

Teacher temperature at 0. Cause: \(\tau _{t}\) is 0, so the teacher shares are all-or-nothing. Symptom: k-NN falls far below the working setup. Fix: keep \(\tau _{t}\) above 0; warm it up from 0.04.

Teacher copied every step (lambda 0, the fastest update). Cause: the teacher is replaced by the student each step. Symptom: training fails to converge. Fix: keep lambda high, so the teacher follows slowly.

Tips. Warm \(\tau _{t}\) up from 0.04 to 0.07 over the first 30 epochs. Keep the center rate at 0.9. Keep the student temperature higher than the teacher’s.
