1 Big picture

In 2012, image classifiers ran on hand-built features. Neural networks deep enough to beat them were too slow to train and would overfit 1.2 million images. Krizhevsky, Sutskever and Hinton built one anyway: 5 convolution layers and 3 fully connected layers, about 60 million weights [1].

Training is ordinary stochastic gradient descent with momentum: one forward and one backward pass per mini-batch, with dropout switched on only during training. Today AlexNet is historical; it lives on as a teaching network and as a small pretrained feature extractor in torchvision.

2 ReLU: units that keep learning

The usual activation in 2012 was tanh. A tanh unit saturates: once its input grows, its output barely moves, so its weights barely change and training slows. AlexNet used the rectified linear unit, ReLU (named by Nair and Hinton [2]):

ReLU, its slope, and tanh's slope for comparison.
\(\displaystyle {f(x) = \max(0,\, x)}\)
Passes positive inputs unchanged and outputs zero otherwise.
\(\displaystyle {f'(x) = \begin{cases} 1 & x > 0 \\ 0 & x < 0 \end{cases}}\)
Its slope is one wherever the unit is active, however large the input.
\(\displaystyle {\tanh'(x) = 1 - \tanh^2(x)}\)
tanh's slope: one at zero, near zero for large inputs.
The weight update a unit receives is scaled by its slope, so a saturated tanh unit gets almost none and an active ReLU unit gets the full step.

On the same small network, ReLU trained much faster than tanh, because its slope never saturates:

Every unit gets the same error signal from above; only the slope at its input differs.

3 Two GPUs

One GPU's memory was too small for the whole network. So half of each layer's kernels sat on each GPU, and the GPUs exchanged activations only at certain layers: into conv3 and into the fully connected layers (Figure 1). The paper credits the split with lower error than a net with half as many kernels per layer on one GPU [1].

4 Dropout in the classifier

About 60 million weights overfit 1.2 million images. AlexNet applied dropout with probability 0.5 in the first two fully connected layers: each training step zeroes a random half of their units, so no unit can rely on a particular partner [3]. The cost is roughly twice as many iterations to converge. The mechanism is on Dropout.

5 Overlapping pooling

AlexNet's max-pooling windows are 3 wide and step by 2, so neighbouring windows share a cell. Compared with windows 2 wide at step 2, the paper reports lower error and slightly less overfitting [1].

In PyTorch the two pools differ only in the window size; on AlexNet's first feature map both give the same output size.

import torch, torch.nn as nn

x = torch.randn(batch, channels, height, width)  # conv1 output: N, C, H, W
overlap = nn.MaxPool2d(3, 2)            # (window, stride): windows share a cell
plain = nn.MaxPool2d(2, 2)              # windows share nothing
overlap(x).shape                        # same output size as the plain pool
plain(x).shape                          # same output size as the overlap pool

6 Data augmentation

AlexNet trained on random 224×224 crops of the 256×256 images, with horizontal flips. It also shifted each image's colours along the principal components of the training set's pixel colours, so the label stays the same under a change of lighting. More on Regularization.

9 In practice

torchvision.models.alexnet(weights=...) loads a pretrained model; torchvision's version is the one-GPU variant from Krizhevsky's later "One weird trick" paper [6], not the two-lane original.

features = nn.Sequential(                     # (N, 3, 224, 224)
    nn.Conv2d(3, 64, 11, stride=4, padding=2), nn.ReLU(inplace=True), nn.MaxPool2d(3, 2),
    nn.Conv2d(64, 192, 5, padding=2), nn.ReLU(inplace=True), nn.MaxPool2d(3, 2),
    nn.Conv2d(192, 384, 3, padding=1), nn.ReLU(inplace=True),
    nn.Conv2d(384, 256, 3, padding=1), nn.ReLU(inplace=True),
    nn.Conv2d(256, 256, 3, padding=1), nn.ReLU(inplace=True), nn.MaxPool2d(3, 2),
)                                             # -> (N, 256, 6, 6)
flat = nn.Flatten()                           # -> (N, flat_size)
classifier = nn.Sequential(
    nn.Dropout(0.5), nn.Linear(flat_size, 4096), nn.ReLU(inplace=True),
    nn.Dropout(0.5), nn.Linear(4096, 4096), nn.ReLU(inplace=True),
    nn.Linear(4096, 1000),                    # -> (N, 1000) class scores
)
model = nn.Sequential(features, flat, classifier)
model.train()                                 # dropout on: random units zeroed each step
model.eval()                                  # dropout off for evaluation
  1. 1The feature stack in torchvision's one-GPU widths: ReLU after every conv, overlapping 3-wide pools.
  2. 2The classifier with dropout in the first two fully connected layers, switched by train() and eval().

AlexNet mixed 11×11, 5×5 and 3×3 kernels. What happens if every layer uses only 3×3 and the network gets much deeper? VGG tried it.
