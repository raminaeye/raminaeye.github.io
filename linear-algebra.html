Vectors and Matrices

How models compare vectors and how matrices move them.

On this page

Models work on lists of numbers. Three tools carry almost every later page: length (clipping), the dot product and angle (attention, PCGrad) and matrices, which move a whole space at once (linear layers, RoPE, LoRA).

1 Everything is a vector

A vector is an ordered list of numbers, drawn as an arrow from the origin. Attention, convolutions, multitask learning and Multilayer Perceptrons (MLP) all store data this way. In shapes such as (B, T, d), each size names an axis: B counts examples, T positions in a sequence and d numbers per vector. A token is a word piece; its embedding is its learned vector.

2 Length is the norm

Clipping in RNNs caps the length of a gradient (how the loss, the model's error score, changes as each weight, a learned number, moves), GradNorm balances gradient lengths, and k-means and k-NN measure distances as lengths. PyTorch's clip_grad_norm_ rescales a gradient so its length is at most max_norm (Optimizers in Practice).

clipping one illustrative gradient g = (3, 4)result
length of g√9 + 16 = 5
max_norm 1scaled by 1/5 to (0.6, 0.8), length 1, same direction
max_norm 10unchanged, 5 is under the cap
a real modelevery weight's gradient joins one long vector, capped as a whole
The length of an arrow, by Pythagoras: square each entry, add, take the square root.
‖a‖ = √a12 + a22 + … + ad2
a1 to ad are the d entries of a; the double bars mean length. Squaring stops signs from cancelling, adding collects every axis, and the square root returns to the entries’ units.
‖a‖ = √Σi ai2
Σi adds the term for every i from 1 to d. A distance is the length of a difference, ‖a − b‖.

3 The dot product scores agreement

Attention scores keys against a query with dot products (Attention), and so does a convolution; CLIP and contrastive learning use the cosine. Each token has a query, what it looks for, a key, what it offers, and a value, what it passes on. The query and keys below are illustrative.

query q = (2, 2) against keyentry by entryscore
cat (2, 2)4 + 48
the (1, 0)2 + 02
sat (−1, −0.5)−2 − 1−3

Attention turns the raw scores 8, 2 and −3 into attention weights, shares that add to 1.

Multiply matching entries and add. The score is large when both arrows are long and point the same way, 0 at right angles, and negative when they point apart.
a · b = Σi ai bi
aibi is the agreement on axis i, positive when both entries share a sign; Σi adds it over all d axes. So the score grows with both lengths and with how well the arrows line up.
a · b = aT b
The same number as a row times a column. The raised T, the transpose, turns the column a into a row; attention writes its scores this way.
‖a‖ = √a · a
A vector’s dot product with itself is the sum of its squares, so the norm of Section 2 is its square root.
keyscorekey lengthcosine
cat (2, 2)82.8281
the (1, 0)210.707
sat (−1, −0.5)−31.118−0.949
the, doubled to (2, 0)420.707

The query’s length is 2.828. Doubling a key doubles its score and leaves its cosine alone.

The dot product with both lengths divided out, so only direction is left: 1 for the same direction, 0 at right angles, −1 for opposite.
cos θ = a · b‖a‖ ‖b‖
θ is the angle between the arrows. The top is the dot product above; each length on the bottom removes one arrow’s size, so stretching an arrow moves the score but not the cosine.

CLIP scales every embedding to length 1 first, so one matrix product (Section 6) gives all its cosines at once. Attention skips that, so a longer key earns a bigger score.

4 Projection keeps one direction

PCGrad removes the part of one task’s gradient that fights another, GradVac and multitask learning measure the fight by the cosine, and PCA scores a face along one direction. A task gradient is the gradient of one task’s loss with respect to the shared weights (Introduction to Multitask Learning).

The part of a that points along b. Subtracting it leaves the part of a at a right angle to b.
projb a = a · b‖b‖2 b
The top is the dot product of Section 3, the overlap of a with b. Dividing by ‖b‖2 turns it into a count of b-lengths, negative when a leans away, and the final b lays that count along b’s line.
a − projb a
The rest is orthogonal to b: its dot product with b is 0. PCGrad keeps only this part when two task gradients have a negative dot product.

5 A matrix times a vector is a layer

Every linear layer is this product: the hidden (inner) layer of an MLP, the query, key and value maps of Attention, and the weight row of logistic and linear regression. A matrix is a table of numbers, read as a stack of rows.

an MLP's hidden layer on the point x = (−2, 2)row of W times xplus biasoutput
row 1 (−1, 1)(−1)(−2) + (1)(2) = 4−22
row 2 (1, −1)(1)(−2) + (−1)(2) = −4−2−6

The weights, the bias (−2, −2) and the point are those of the MLP walkthrough.

Each output is the dot product of one row of W with the input, plus a bias.
y = W x + b
x has n entries, W is an m × n matrix (m rows, n columns), and the bias b shifts each of the m outputs in y.
yi = Wi · x + bi
Row Wi is the direction output i listens to, so each output is a dot product from Section 3 plus its bias. A layer is m dot products at once.

6 Shapes, batches and other products

Score tables in Attention and Transformer Cost and Efficiency, padding masks, cross-attention, Adam (Optimizers) and pruning masks follow these rules.

6.1 Inner sizes match, outer sizes survive

Take six tokens at the original Transformer’s width 512: X has shape (6, 512). WQ, shape (512, 64), turns each token into a 64-number query, so dk = 64 is the query width. K stacks the keys the same way, S is the score table and h counts attention heads (parallel copies of attention).

In a batch, the axes before the last two ride along. An axis of size 1 stretches to match the other side, which is called broadcasting. @ is the matrix product sign in NumPy and PyTorch.

operationshapesresult
scores per head(1, 8, 16, 64) @ (1, 8, 64, 16)(1, 8, 16, 16)
padding mask (hides filler tokens) on the scores(2, 1, 1, 5) with (2, 8, 5, 5)(2, 8, 5, 5), the mask reaches every head and query
GMM: each point’s 2 cluster scores divided by their total(272, 1) with (272, 2)(272, 2)

The sizes come from the RoPE code and the padding-mask code in Positional Encoding and Masking, and from the 272 points of the tool in GMMs.

A matrix product pairs every row on the left with every column on the right. The inner sizes must match and the outer sizes survive.
(m × n)(n × p) = (m × p)
Each of the m rows meets each of the p columns in one dot product of length n, the layer of Section 5 run on p inputs at once, so n must agree on both sides and then disappears.
(…, m, n)(…, n, p) = (…, m, p)
@ multiplies the last two axes and treats the axes before them as a batch. With h attention heads, queries (B, h, T, dk) times transposed keys give one (T, T) score table per example and head.

6.2 Two readings of a product

A LoRA update is a small change added to a frozen (kept fixed) weight, built as a column times a row (Adapters).

readingexampleresult
a row of AV blends the rows of VAttention's weights 0.78, 0.17, 0.05 on illustrative value rows (1, 0), (0, 1), (1, 1)(0.83, 0.22)
two layers in a row are one layeran illustrative rank-1 LoRA update (rank 1: every output lies on one line, Section 8) on x = (1, 1): the row (1, 1), then the column (2, 1)the row gives 2, the column turns it into (4, 2); their product 2211 gives (4, 2) at once
The same product read two ways: each output row is a weighted sum of rows, and a chain of matrices folds into one.
(A V)i = Σj Aij Vj
The product of Section 6.1, read row by row: output row i blends the rows Vj of V with the weights Aij. In attention A holds the softmax weights (positive, summing to 1) and V the values; multitask learning blends task gradients the same way.
W2(W1 x) = (W2 W1) x
W2W1 is one matrix, computed once, so two linear layers with nothing between them are one layer. That is why an MLP puts a nonlinearity (a bend no matrix makes) such as ReLU between layers, and why Adapters can merge a LoRA update (W1 the row, W2 the column) into the weight.

6.3 Entry by entry, and the outer product

⊙ multiplies matching entries. Adam keeps two running averages: one of the gradient, and v, one of its square (Optimizers).

operationexampleresult

Two products that keep every entry instead of summing. The outer product pairs every entry with every other.
(a ⊙ b)i = ai bi
The dot product of Section 3 without its Σ. Adam scales each coordinate by its own 1/√v (Gradient Balancing Inside the Training Loop), pruning and dropout masks zero chosen entries, and Conformer and LSTM gates multiply one signal by another.
(e xT)ij = ei xj
One entry per pair, a rank-1 matrix (Section 8). A weight gradient is this table, each output’s error ei times each input xj (Backpropagation).

7 The determinant measures area

A GMM’s formula for how likely a point is (its density) divides by the square root of the determinant of its covariance (the spread of each component, one Gaussian bump); when one component shrinks onto a point, that determinant nears 0 and the likelihood (how well the model explains the data) runs to infinity (Gaussian Mixture Models (GMM)). LayerNorm rescales each feature (one entry of a vector) by a learned γ (The Transformer Block). RoPE turns a query or key by an angle set by its position (Positional Encoding and Masking).

matrixentries a, b, c, dad − bcthe plane
illustrative γ = (2, 1) as a diagonal matrix2, 0, 0, 12areas double
RoPE turn by 40°0.766, −0.643, 0.643, 0.7661areas, lengths and angles kept
rank-1 LoRA update2, 2, 1, 10lands on one line
the MLP walkthrough’s W from Section 5−1, 1, 1, −10both outputs read only x2 − x1

The LoRA update is illustrative too; 40° is one position’s turn in the RoPE figure of Positional Encoding and Masking. A diagonal matrix scales each axis on its own, as LayerNorm’s γ and a diagonal covariance in GMMs do.

The factor by which a 2 × 2 matrix scales area. A determinant of 0 means the matrix flattens the plane onto a line or a point.
det abcd = ad − bc
The columns (a, c) and (b, d) are where the sides of the unit square (corners (0, 0) and (1, 1)) land, and ad − bc is the area of the parallelogram they span; when b = c = 0 it is just the rectangle ad. For a layer’s W from Section 5, it says how much every region of the input is stretched or squashed.
vol(W C) = |det W| vol(C)
C is any region, WC where W moves it, vol its volume (area when n = 2) and the bars drop the sign. For any n × n matrix the determinant is this one scale factor; np.linalg.det computes it, and the GMM above needs it for its covariance, one row and column per feature.

8 Inverse and rank

Linear regression’s direct formula for the best weights contains an inverse, RoPE needs a turn that can be undone (Positional Encoding and Masking), and LoRA (Adapters) and collapse checks count rank. Correlation says how strongly two pixels brighten together, 1 meaning always (Probability and Bayes Rule).

matrixdetinverse
two face pixels from PCA's faces, correlation 0.61: 10.610.6110.6281.593−0.971−0.9711.593; times the matrix it gives the identity I (1s on the diagonal from top left to bottom right, 0s elsewhere)

The inverse is the move that undoes a matrix. It exists only when the determinant is not 0, because a flattened plane cannot be spread out again.
W−1 W = I
I, the identity from the table, moves nothing; W then W−1 puts every point back.
R−1 = RT
Turning back undoes turning, so a turn’s transpose is its inverse.

RoPE turns each query and each key by the angle of its own position, then scores the pair with a dot product.

Two turns combine into one turn by their difference, so a turned query and key score by how far apart they sit, not where.
RmT Rn = Rn−m
Here m and n are positions, not sizes: Rm turns by the angle of position m, and its transpose, the inverse from the card above, turns back. Back by m, then forward by n, is one turn by n − m.
(Rm q)T(Rn k) = qT Rn−m k
The score of a query q at position m and a key k at position n, the dot product of Section 3 after both turn. By the line above it depends on the gap n − m alone.

The rank is the number of independent directions left after the move; a rank-r matrix is a sum of r outer products (Section 6.3). The illustrative LoRA update is the column (2, 1) times the row (1, 1), so r = 1, the shape of every LoRA update: a tall thin matrix times a short wide one. Embeddings that use few directions have low rank, the collapse the checks look for.

Clipping and attention scores in NumPy. Clipping runs once per training step (one weight update), after the gradients are computed; scores run every time the model runs.

import numpy as np
g = np.array([3.0, 4.0])  # an illustrative gradient
max_norm = 1.0
length = np.linalg.norm(g)  # 5.0
clipped = g * min(1.0, max_norm / length)  # [0.6 0.8]

q = np.array([2.0, 2.0])  # query
keys = np.array([[2.0, 2.0],  # cat
                 [1.0, 0.0],  # the
                 [-1.0, -0.5]])  # sat
scores = keys @ q  # [ 8.  2. -3.]
key_len = np.linalg.norm(keys, axis=1)
cosines = scores / (key_len * np.linalg.norm(q))
# [ 1.     0.707 -0.949]
  1. 1Clips the gradient (3, 4) to length 1, Section 2.
  2. 2Scores three keys against one query in a single matrix-vector product, Section 3 and Section 5.
  3. 3Divides out both lengths to get the cosines, Section 3.

Layer and mask shapes in PyTorch. The layer runs every time the model runs; the mask is built once per batch.

import torch
import torch.nn as nn

Determinant, rank, inverse and solve in NumPy, run once on fixed matrices.

import numpy as np
corr = np.array([[1.0, 0.61], [0.61, 1.0]])  # face pixels
lora = np.array([[2.0, 2.0], [1.0, 1.0]])  # rank-1 update
w1 = np.array([[-1.0, 1.0], [1.0, -1.0]])  # the MLP walkthrough's layer

dets = [np.linalg.det(m) for m in (corr, lora, w1)]  # 0.628, 0, 0
ranks = [np.linalg.matrix_rank(m) for m in (corr, lora, w1)]  # 2, 1, 1
inv_corr = np.linalg.inv(corr)  # [[1.593 -0.971] [-0.971 1.593]]

z = np.linalg.solve(corr, np.array([1.0, 1.0]))  # [0.621 0.621]
  1. 1Sets up the three matrices of Section 7 and Section 8.
  2. 2Reads each one's determinant and rank, and inverts the one that has an inverse.
  3. 3Solves the correlation matrix times z = (1, 1) for z directly, with no inverse formed.

Four traps catch most shape and matrix bugs.

  • A (B, T) mask on (B, h, T, T) scores lines up with the last two axes: it fails, or silently masks the wrong entries when B equals T. Reshape it to (B, 1, 1, T).
  • nn.Linear stores (out, in), so a product by hand needs x @ W.T.
  • A dot product is a cosine only after F.normalize (PyTorch’s scale to length 1).
  • Solve, do not invert: np.linalg.solve or lstsq skips the error that forming the inverse adds. With near-copy features the matrix is close to having no inverse, and the solved weights swing either way. Its condition number, how much a small error in the data can grow in the answer, measures this; its determinant does not.
