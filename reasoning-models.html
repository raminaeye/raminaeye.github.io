Reasoning Models: Long Thinking Inside an Agent

Rewarding only a correct final answer can still teach a model to pause and check itself.

1 The model that learned to pause

Most language models answer straight from what they learned in training. A reasoning model does something else first: it thinks, in writing, for a long time, and only then answers. That long thinking is what this page is about, and it matters for agents, because an agent that thinks before it acts makes fewer blind moves.

The model that showed this most clearly is R1-Zero. It starts from a base model, a model trained only to predict the next word, and learns by reinforcement learning: it tries answers, gets a reward for the ones that work, and shifts toward what earned the reward (RL Basics). There is no supervised fine tuning first, no set of worked answers to copy. The reward judges only the final answer, never the thinking in between.

Training is reinforcement learning over many sampled answers per question. At inference the model thinks long once per question, with no state carried between questions. What it carries within one question is the thinking it has written so far, the chain of thought it builds as it goes.

2 Reward only the final answer

This section leans on the GRPO page for the group comparison that turns rewards into an update.

This family has a name: reinforcement learning with verifiable rewards. A verifier is a program that can check an answer: a math answer against the known one, code against its test cases. The survey of RL techniques for language models notes that this kind of reward improves stepwise reasoning, because the check is objective. It cannot be flattered.

2.1 The two checks

The reward is two checks, added together. The accuracy reward pays when the final answer is right, as judged by a program. The format reward pays when the reasoning sits inside think tags, the markers that fence off thinking from the answer. The tags make the thinking visible and easy to read back.

No learned scorer grades the reasoning. The paper holds back from neural reward models here, because a learned scorer can be gamed during large scale training: the model learns to please the scorer instead of solving the problem. A program check has no opinion to flatter.

Equation 1. The rule reward. Two checks, each worth one, added with the same weight.
\(\displaystyle \htmlClass{eqt sym-r}{\htmlStyle{color:var(--sym-r)}{r_{\mathrm{rule}}}}=\htmlClass{eqt sym-r}{\htmlStyle{color:var(--sym-r)}{r_{\mathrm{acc}}}}+\htmlClass{eqt sym-r}{\htmlStyle{color:var(--sym-r)}{r_{\mathrm{fmt}}}}\)
A program gives one for a right final answer and one more for reasoning inside think tags, so a right and well formed answer earns both and a wrong, untagged one earns neither. \(r_{\mathrm{acc}}\) is the accuracy reward; \(r_{\mathrm{fmt}}\) is the format reward; \(r_{\mathrm{rule}}\) is their sum. The two checks carry the same weight.
\(r_{\mathrm{rule}}\) the rule reward \(r_{\mathrm{acc}}\) the accuracy reward \(r_{\mathrm{fmt}}\) the format reward
The paper writes this as Reward with subscripts acc and format (paper equation 4).
The group comparison that turns these rewards into an update is taught on the GRPO page; the objective itself is taught there, not here.

Those two checks feed the group comparison on the GRPO page: each answer’s advantage is how much better it scored than the group’s mean, and the update pushes the policy, the model’s current way of choosing answers, toward the answers above the mean. The objective itself is taught there, not here.

The mean line marks the mean score of the group’s answers to the same question: add the group’s scores and divide by how many answers there are. An answer above the line earns a push up, and an answer below it earns a push down. That comparison is the whole update: the group sets the bar, and no separate critic, a second model that scores answers on its own, is needed.

3 The aha moment

This section leans on the GRPO page for the group comparison and on the DeepSeek-R1 page for the pipeline stages.

Nothing in the reward asks for long thinking. The reward pays for right answers, and long thinking is what earns them. Over training the answers grow longer, and new habits appear inside them: the model verifies its own steps, reflects on them, and tries another approach when one stalls.

The clearest habit is the pause. Midway through training the model starts using the word wait in its reflections, stopping to flag its own step and rework it. The paper calls this the aha moment, and prints one trace where the model writes: “Wait, wait. Wait. That is an aha moment I can flag here.” The moment marks a change in how the model reasons, not just a longer answer.

Longer thinking is not taught. It is what survives: answers that pause and recheck land right more often, so the update pushes the policy toward them. That is the whole mechanism of this page: reward the end, and the middle teaches itself.

The share bar counts how many of the group’s answers were correct: the bar fills further as more of the group lands right.

4 Cold start and the full pipeline in brief

R1-Zero thinks long, but its answers are hard to read and mix languages. The full model fixes that with a cold start: before any reinforcement learning, it is fine tuned on a small set of readable worked answers, so its thinking starts in good shape.

From there the pipeline runs four more stages: reasoning RL with the rule rewards and a language check, rejection sampling that keeps the good answers and fine tunes on them, a second RL stage over all prompts, and distillation that teaches the long thinking to smaller models. The stages are taught in full on the DeepSeek-R1 page, which steps through them one by one.

The cold start matters for agents: it is what turns a model that can reason into one whose reasoning an agent can read, check, and build on.

5 Practice

Each training question costs a group of sampled answers: the paper samples 16 answers per question (paper section 2.1), scores each with the rule reward, and updates from the group. At inference each question costs one long generation, the thinking plus the answer.

The headline setting is the rule based reward as accuracy plus format (DeepSeek-R1 equation 4). The two checks carry the same weight, and no learned scorer grades the reasoning.

The official repository is github.com/deepseek-ai/DeepSeek-R1, verified live. It carries the model weights, the paper, and instructions for running the model. It carries no training code: the paper released no code for the training run itself, so there is no official implementation to link, and no community copy is linked here.

6 Failure modes

Four failures cover most of what goes wrong. Each has a cause, a visible symptom, and a fix.

6.1 Mixed languages and unreadable reasoning

Cause: reinforcement learning alone rewards right answers and never readability. Symptom: the thinking switches languages mid-answer and is hard to follow. Fix: cold start fine tuning on readable worked answers, plus a language consistency reward in reasoning RL.

6.2 A learned scorer gets gamed

Cause: a neural reward model scores the reasoning, and the policy learns to please it. Symptom: the scores rise while the answers get worse. Fix: keep rewards rule based wherever the answer can be checked, and keep learned rewards limited where they are needed (DeepSeek-R1).

6.3 Longer answers that only pad

Cause: length itself correlates with reward early on. Symptom: answers grow with extra reasoning that adds no correctness. Fix: the corrected GRPO weighting that stops long answers counting for more (GRPO).

6.4 Small models barely improve

Cause: reinforcement learning from a small base model has little to draw out. Symptom: the same RL run that transforms a large model leaves a small one nearly flat. Fix: fine tune the small model on a large reasoner’s answers instead (DeepSeek-R1).

7 What comes next

ReAct thinks and acts in a loop, MRKL routes to experts, and this page shows a model that learns to think longer by reward alone. The next step is a model that learns to use a tool the same way: by trying it, reading what comes back, and keeping what works.
