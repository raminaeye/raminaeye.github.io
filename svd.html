1 Any matrix, not just a square one

wherewhat is kept
LoRArank 8, a low-rank update, a few columns times a few rows, learned in place of a full weight change
PCAcentred faces, fitted by one SVD
NMF and the audio pagesa spectrogram, SVD’s signed blocks against NMF’s non-negative parts

collapse checksthe count of non-zero eigenvalues; a zero means the outputs lie on a flat slice of the space

One SVD is computed once per matrix; the kept blocks are then reused for every rebuild, every LoRA step and every rating prediction, and nothing is carried between matrices. One SVD grows with the size of the matrix, so large matrices use the randomized SVD in Code B block 3; spectral normalization estimates the largest singular value per weight matrix per training step instead of running a full SVD, and LoRA learns its low-rank factors through training and never runs an SVD.

The problem eigenvectors leave open: they need a square matrix that maps a space to itself. A LoRA update, a users-by-items ratings table, a batch of embeddings and a spectrogram (frequencies by time frames) map one space to another, so their ‘directions that only stretch’ need two sets of directions, one for inputs and one for outputs.

2 Turn, stretch, turn

Spectral norm and PCA in practice read a matrix through its singular value decomposition (SVD). The example is an update in LoRA’s shape, one column times one row, as in Vectors and Matrices, section 8: it stretches one direction and flattens every other (Figure 2).

A
Any matrix is a turn, a stretch along the axes, and another turn.
\(\displaystyle \htmlStyle{color:#7d3c98}{M} = \htmlStyle{color:#0e6b59}{\htmlClass{eqt}{\htmlData{k=U}{U}}} \htmlStyle{color:#a04000}{\htmlClass{eqt}{\htmlData{k=S}{S}}} \htmlStyle{color:#1f618d}{\htmlClass{eqt}{\htmlData{k=VT}{\htmlClass{eqt}{\htmlData{k=V}{V}}^{T}}}}\)
\(V^{T}\) turns the input so the directions \(M\) stretches most lie on the axes. \(S\) is diagonal and stretches axis \(i\) by the singular value \(s_{i}\), largest first. \(U\) turns the result into place. \(U\) and \(V\) are orthogonal, and a zero \(s_{i}\) flattens its direction, as in panel 3 of Figure 2. Singular values are never negative: \(s_{i} \ge 0\) reads as “at least zero, never negative”. Unlike \(C = V \Lambda V^{T}\), the two turns differ and \(M\) need not be square.
\(\displaystyle \htmlStyle{color:#a04000}{\lambda _{i}} = \frac{s_{i}^{2}}{N}\)
Take \(X\), the centred faces, one per row (Covariance from data). Its \(V\) holds the eigenvectors of their covariance, the same \(V\) as in section 4 of Eigenvalues and Eigenvectors, and each eigenvalue is a squared singular value over \(N\): a singular value measures how far the data reaches along its direction, and squaring it and averaging over the \(N\) faces turns that reach into variance. So PCA in practice gets the eigenfaces from one SVD, without building \(C\) (PCA in practice).
\(\displaystyle \htmlStyle{color:#a04000}{s_{1}} = \max_{x \ne 0} \frac{\lVert \htmlStyle{color:#7d3c98}{M} \htmlStyle{color:#1f618d}{x} \rVert}{\lVert \htmlStyle{color:#1f618d}{x} \rVert}\)
The largest singular value is the most \(M\) can stretch any input: the spectral norm.

spectral normalization (Normalization, the spectral-norm section) divides each weight matrix by the largest singular value, estimated by power iteration, repeatedly multiplying by the matrix. One power-iteration round per training update suffices because each update starts from the vector the previous step found, which is already close (Miyato et al. 2018).

3 Singular values are eigenvalues in disguise

In practice, scikit-learn’s PCA fits by SVD of the centred data, without building \(C\).

B
\(\displaystyle \htmlStyle{color:#0e6b59}{X} = \htmlStyle{color:#0e6b59}{U} \htmlStyle{color:#a04000}{S} \htmlStyle{color:#1f618d}{V^{T}}, \text{ so } \htmlStyle{color:#7d3c98}{C} = \frac{1}{N} \htmlStyle{color:#0e6b59}{X}^{T} \htmlStyle{color:#0e6b59}{X} = \htmlStyle{color:#1f618d}{V} \frac{\htmlStyle{color:#a04000}{S}^{2}}{N} \htmlStyle{color:#1f618d}{V^{T}}\)
For centred data with one example per row, the SVD’s input directions are the covariance’s eigenvectors. Terms: \(X^{T} X\) squares the stretches and cancels \(U\), because \(U^{T} U = I\). Dividing by \(N\) matches card B of Eigenvalues and Eigenvectors.

The covariance has one eigenvalue per feature, and the SVD of the same centred data has one non-zero singular value per non-zero eigenvalue, in a list that runs to the smaller of the two matrix dimensions, including zeros; the two lists match on the non-zero entries, and the remaining eigenvalues are zero, with no non-zero singular value.

4 Keep only the biggest stretches

The same truncation compresses a spectrogram, learns a LoRA update of rank \(r\) (Hu et al. 2022), and stores users and items as short vectors for recommenders. NMF keeps every block non-negative, so its blocks add as parts.

Builds on entrywise and outer products (Vectors and Matrices, section 6.3) and a spectrogram as a matrix (The STFT and Spectrograms, section 2)

C
Keep the \(k\) largest stretches and drop the rest.
\(\displaystyle \htmlStyle{color:#7d3c98}{M} \approx \sum_{i\,=\,1}^{k} \htmlStyle{color:#a04000}{s_{i}} \htmlStyle{color:#0e6b59}{u_{i}} \htmlStyle{color:#1f618d}{v_{i}^{T}}\)
\(u_{i}\) and \(v_{i}\) are column \(i\) of \(U\) and \(V\), so \(u_{i} v_{i}^{T}\) is one outer product, a rank-1 block stored as a column, a row and its weight \(s_{i}\). The sum from \(i = 1\) to \(k\) adds the first \(k\) blocks; the nearly-equal sign leaves out the rest, which is the error. The first \(k\) give the best rank-\(k\) copy in squared error (Eckart and Young, 1936). Blocks may hold negative numbers that cancel. NMF (non-negative matrix factorization) keeps every block non-negative, so the blocks add up as parts.
\(\displaystyle \text{kept share} = \frac{\sum_{i\,=\,1}^{k} s_{i}^{2}}{\sum_{i} s_{i}^{2}}\)
The share of \(M\)’s squared size (the sum of its squared entries) that the first \(k\) blocks keep. For centred data each \(s_{i}^{2}\) is \(N\) times an eigenvalue, so this is the eigenvalue share.
\(\displaystyle \Delta W = B A, \qquad \operatorname{rank}(B A) \le r\)
LoRA learns a weight update as a tall thin matrix times a short wide one, so it can never use more than \(r\) directions. Storage grows with the sum of the two sides times \(r\), not their product.

5 SVD in NumPy and PyTorch

One SVD gives the directions, the stretches and the best rank-\(k\) copy of a real spectrogram. The spectrogram is frequency bins by frames; with full_matrices=False, \(U\) is frequency bins by the smaller dimension and \(Vt\) is the smaller dimension by frames, and only the slices U[:, :k] and Vt[:k] have \(k\) blocks.

import numpy as np
import librosa
import torch

y, sr = librosa.load(
    librosa.ex("trumpet"))
spec = np.abs(librosa.stft(y))
# (freq_bins, frames)
U, s, Vt = np.linalg.svd(
    spec, full_matrices=False)
# returns Vᵀ, largest s first
spectral_norm = s[0]
k = 8  # a setting: blocks to keep
rank_k = (U[:, :k] * s[:k]) @ Vt[:k]
kept = (s[:k] ** 2).sum() / (s ** 2).sum()

U_k, s_k, V_k = torch.svd_lowrank(
    torch.from_numpy(spec), q=k)
# returns V, not Vᵀ
